    • ARC111D Orientation

    • 若 \(u \to v\)，则 \(R(v) \subseteq R(u)\)，故 \(c_u \ge c_v\)。因此 \(c_u > c_v\) 定向 \(u \to v\)，\(c_u < c_v\) 定向 \(v \to u\)。

    • 若 \(c_u = c_v\)，则必须 \(R(u)=R(v)\)，即 \(u,v\) 强连通。相同 \(c\) 的连通块必须定向为强连通图。

    • 题目保证有解 \(\Rightarrow\) 这些连通块无桥。DFS 定向：树边父 \(\to\) 子，非树边子孙 \(\to\) 祖先，即强连通。

    • 实现：不同 \(c\) 直接定向；相同 \(c\) 的边 DFS，未访问则 \(u \to v\) 并递归，已访问则 \(u \to v\)（\(v\) 是祖先）。

    • C. Spóźnienia

    tag : 数学推导 滑动窗口

    • 定义

    \(A_i \text{ 表示骑士 } i \text{ 的发言时长}\)

    \(B_i \text{ 表示骑士 } i \text{ 的到达时间}\)

    \(End_i \text{ 表示骑士 } i \text{ 发言结束的时刻}\)

    • 递推式

    \(End_i = \max(End_{i-1}, B_i) + A_i\)

    • 推导展开

    \(End_i = \max(0, B_i) + A_i = B_i + A_i\)

    \(End_{i+1} = \max(End_i, B_{i+1}) + A_{i+1}\)

    \(= \max(B_i + A_i, B_{i+1}) + A_{i+1}\)

    \(= \max(B_i + A_i + A_{i+1}, \ B_{i+1} + A_{i+1})\)

    \(End_{i+2} = \max(End_{i+1}, B_{i+2}) + A_{i+2}\)

    \(= \max(\max(B_i + A_i + A_{i+1}, \ B_{i+1} + A_{i+1}), \ B_{i+2}) + A_{i+2}\)

    \(= \max(B_i + A_i + A_{i+1}, \ B_{i+1} + A_{i+1}, \ B_{i+2}) + A_{i+2}\)

    \(= \max(B_i + A_i + A_{i+1} + A_{i+2}, \ B_{i+1} + A_{i+1} + A_{i+2}, \ B_{i+2} + A_{i+2})\)

    • 归纳通项

    \(Ans_i = End_{i+N-1} = \max_{k=i}^{i+N-1} \left( B_k + \sum_{j=k}^{i+N-1} A_j \right)\)

    • 前缀和优化

    \(设 \ S_k = \sum_{j=1}^k A_j \ ，则 \ \sum_{j=k}^{i+N-1} A_j = S_{i+N-1} - S_{k-1}\)

    \(Ans_i = \max_{k=i}^{i+N-1} \left( B_k + S_{i+N-1} - S_{k-1} \right)\)

    \(= S_{i+N-1} + \max_{k=i}^{i+N-1} \left( B_k - S_{k-1} \right)\)

    • 转化为滑动窗口

    \(令 \ C_k = B_k - S_{k-1} \ ，则最终公式为：\)

    \(Ans_i = S_{i+N-1} + \max_{k=i}^{i+N-1} (C_k)\)

    • D. Domino Fibonacciego

    tag : 构造 dfs

    • E_P9912 [COCI 2023/2024 #2] Zatopljenje

    tag : 模型转化 数据结构 离线处理

    • 核心：岛数 \(=\) 区间内满足 \(h_i > x\) 的点数 \(-\) 相邻且两端都满足 \(h_i > x\) 的边数

    • 相邻边条件等价于：\(\min(h_{i-1}, h_i) > x\)

    • 离线：

    • 点：位置 \(i\)，权值 \(h_i\)

    • 边：位置 \(i\) 表示相邻位置 \((i-1, i)\)，权值 \(\min(h_{i-1}, h_i)\)，其中 \(i \in [2, n]\)

    • 所有询问按 \(x\) 从大到小排序

    • 点和边也按权值从大到小排序

    • 用双指针扫描，把权值 \(> x\) 的点和边分别加入两个树状数组

    • 对询问 \([l, r, x]\)：

    • 点数 \(= \text{query}(r) - \text{query}(l - 1)\)

    • 边数 \(= \text{query}(r) - \text{query}(l)\)

    • ans \(= \text{点数} - \text{边数}\)

    • P8867 [NOIP2022] 建造军营

    • 终于改过了！

    • 发现是树形 DP 的状态不完整。

    • 需要对缩点后的子树的建造数分别计数。

    • 核心：缩点成树后，军营连通块对应树上的一棵最小子树

    • 桥必须看守，边双内部边自由（每条可选 \(2\) 种，最后统一乘 \(2^{m-\text{edcc}+1}\)）。

    • 树上 DP 需要三个状态：

    • \(f0[u]\)：子树内无军营；

    • \(f1[u]\)：子树内有军营，且 \(u\) 在军营连通块中；

    • \(f2[u]\)：子树内有军营，但 \(u\) 不在军营连通块中。

    • 转移时注意边 \((u,v)\) 看守与否的选择数：

    • 从 \(f0\) 接入 \(f1\) 时，若看守边，则 \(u\) 进入连通块 → 归入 \(f1\)（\(1\) 种）；

    • 若不看守边，则 \(u\) 不进入连通块 → 归入 \(f2\)（\(1\) 种）。

    • 不能两者都乘 \(2\)，否则会重复计数并漏掉 \(f2\)。

    • 最终答案：\((f1[\text{根}] + f2[\text{根}]) \times 2^{m - \text{edcc} + 1} \bmod 10^9+7\)。

    • CF1946F Nobody is needed

    tag : DP 数据结构

    • 把"区间内整除链计数"离线拆成"从右往左枚举左端点 + 在终点打标记求前缀和"

    • 而每条链只挂在它首元素的倍数上，所以时间复杂度是对的

    • 详细：

    • 按终点分桶：一条链首下标 \(\ge l\)、末下标 \(\le r\) 就必在 \([l,r]\) 内，于是询问 = 对"终点位置"的前缀和，区间计数 → 前缀和问题。

    • 滚动左端点 \(l\)（差分）：\(S_l=S_{l+1}+C_l\)，\(l\) 从 \(n\) 降到 \(1\) 时只需累加"以 \(l\) 为起点"的增量 \(C_l\)，不重算。

    • 性质：链长 \(\le\log_2 n\)，且链头为 \(a_l\) 后所有元素都是 \(a_l\) 的倍数 → \(C_l\) 只在 \(a_l\) 的倍数处非零，规模 \(\sum n/a_l=O(n\log n)\)。

    • 值域 DP：按值从小到大枚举倍数，把 \(C_l(y)\) 推给后继 \(z\)（前驱值必更小，天然有序），用 \(pos[z] >= pos[y]\) 保证下标递增；结果单点加进树状数组，询问取前缀和。

    • 复杂度 \(O(n\log^2 n+q\log n)\)。

    T3比较数学,具体推导如下:

    • T3

    • 暴力是枚举 。突破口是：\(\gcd(i,n)\) 的取值非常少——它一定是 \(n\) 的约数，而 \(10^7\) 以内约数最多的数也只有几百个约数。所以改为枚举 \(d=\gcd(i,n)\)，数一数有多少个 \(i\) 取到这个 \(d\)。

    • 计数：\(\gcd(i,n)=d\) 成立，首先要 \(d\mid n\) 且 \(d\mid i\)。设 \(i=d\cdot k\)，\(n=d\cdot m\)，则

      \(\gcd(i,n)=d \iff \gcd(k,m)=1\)

    • \(k\) 在 \([1,m]\) 中与 \(m=\frac{n}{d}\) 互质的个数，正好就是欧拉函数的定义：\(\varphi\left(\frac{n}{d}\right)\) 个。每个这样的 \(i\) 贡献 \(\frac{n}{d}\)，于是

      \(\sum_{i=1}^{n}\frac{n}{\gcd(i,n)} = \sum_{d\mid n}\varphi\left(\frac{n}{d}\right)\cdot\frac{n}{d}\)

    • 最后一步换元：\(d\) 跑遍 \(n\) 的所有约数时，\(\frac{n}{d}\) 也跑遍所有约数，把 \(d\) 换成 \(\frac{n}{d}\) 得到

      \(f(n)=\sum_{d\mid n}d\varphi(d)\)

    • 复习了数论,并用概率的思想理解了欧拉函数的计算,如下:

    • 由算术基本定理 \(N = p_1^{c_1} p_2^{c_2} \cdots p_m^{c_m}\)，则：

      \[ \varphi(N) = N \cdot \frac{p_1 - 1}{p_1} \cdot \frac{p_2 - 1}{p_2} \cdots \frac{p_m - 1}{p_m} = N \cdot \prod_{i=1}^{m} \left(1 - \frac{1}{p_i}\right) \]

    证明:

    • 假设要在 \(1 \sim N\) 里挑一个数，它不能是 \(p_1\) 的倍数。

      \(1 \sim N\) 里，是 \(p_1\) 倍数的数占了 \(\frac{1}{p_1}\)，所以不是 \(p_1\) 倍数的数就占了 \(\left(1 - \frac{1}{p_1}\right)\)。

      同理，它不能是 \(p_2\) 的倍数，剩下的概率再乘以 \(\left(1 - \frac{1}{p_2}\right)\)。

      因为这些质因数之间是相互独立的，所以我们可以直接把概率乘起来。

      最后，总数 \(N\) 乘以总概率，就是满足与 \(N\) 互质的个数了。

    • CF1515E Phoenix and Computers

    • 思路

    • 若有 \(k\) 个手动连续块，则自动打开 \(k-1\) 台，手动打开总数 \(m=n-k+1\)，且需 \(m\ge k\)，即 \(k\le \lfloor (n+1)/2\rfloor\)。

    • 长度为 \(L\) 的手动连续块内部合法顺序数为 \(2^{L-1}\)，因为每次最后手动打开的只能是当前剩余段的端点。

    • 若第 \(i\) 块长度为 \(l_i\)，则交错合并方案数为 \(\frac{m!}{\prod_{i=1}^k l_i!}\)，总贡献为 \(m!\prod_{i=1}^k \frac{2^{l_i-1}}{l_i!}\)。

    • 设 \(w[L]=\frac{2^{L-1}}{L!}\)，令 \(dp[i][j]\) 表示手动总数 \(i\)、分成 \(j\) 个连续块的权重和： \(dp[i][j]=\sum_{L=1}^{i}dp[i-L][j-1]\cdot w[L]\) 初始 \(dp[0][0]=1\)。

    • 答案为 \(ans=\sum_{k=1}^{\lfloor (n+1)/2\rfloor} fac[n-k+1]\cdot dp[n-k+1][k]\)。

    • 复杂度 \(O(n^3)\)，空间 \(O(n^2)\)。
