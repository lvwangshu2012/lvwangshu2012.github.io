    线性DP专题笔记 Day1¶

    涵盖 按位DP、计数DP、区间调度转化、树形DP、线段树优化DP 等多种 线性DP 经典题型

    ---¶

    A 绝世好题（P4310）¶

    题型¶

    按位优化线性DP / 类LIS问题

    题意¶

    给定长度为 \(n\) 的数列 \(a_i\)，求最长子序列 \(b_i\)，满足任意相邻两项的按位与不为 0（\(b_i \& b_{i-1} \ne 0\)）。

    核心思路¶

    跳出传统“按序列位置DP”的思路，利用二进制位的性质优化状态：两个数按位与非零等价于至少有一个公共的二进制位为1。因此只需维护每个二进制位对应的最长子序列长度，即可完成转移。

    DP状态定义¶

    • \(f[c]\)：所有以第 \(c\) 个二进制位为1的数字结尾的合法子序列的最长长度。

    转移流程¶

    对每个数字 \(x\)： 1. 枚举 \(x\) 所有为1的二进制位，取对应 \(f[c]\) 的最大值，加1得到以 \(x\) 结尾的最长合法子序列长度 \(cur\)； 2. 用 \(cur\) 更新 \(x\) 所有为1的二进制位的 \(f[c]\)。

    答案¶

    遍历所有数字的 \(cur\)，取最大值。

    复杂度¶

    时间：\(O(n \times 32)\)，空间：\(O(32)\)

    关键细节与坑点¶

    1. 处理每个新数字前，必须重置当前长度变量 \(cur\)，否则上一个数字的结果会残留，导致答案偏大；
    2. 左移写法注意整型溢出，建议用 (x >> c) & 1 的位运算写法；
    3. 数字0无法与任何数按位与非零，只能单独作为长度为1的子序列。

    核心代码片段¶

    int f[32] = {0};
int ans = 0;
for (int i = 1; i <= n; ++i) {
    int x; cin >> x;
    int cur = 0;
    for (int c = 0; c < 31; ++c)
        if ((x >> c) & 1)
            cur = max(cur, f[c] + 1);
    for (int c = 0; c < 31; ++c)
        if ((x >> c) & 1)
            f[c] = max(f[c], cur);
    ans = max(ans, cur);
}

    B 大师（P4933）¶

    题型¶

    公差状态计数DP

    题意¶

    给定长度为 \(n\) 的数组，求其中所有是等差数列的子序列的总个数，结果对 998244353 取模（单个元素也算合法子序列）。

    核心思路¶

    枚举子序列的最后两项，将“公差”作为DP的第二维状态，递推统计所有等差数列的数量。

    DP状态定义¶

    • \(f[i][d]\)：以第 \(i\) 个元素结尾、公差为 \(d\) 的等差数列子序列的个数（长度≥2）。

    转移方程¶

    对每个 \(i\)，枚举所有 \(j < i\)，令公差 \(d = h_i - h_j\)： $\(f[i][d] = f[i][d] + f[j][d] + 1\)$ 含义： - \(f[j][d]\)：所有以 \(j\) 结尾、公差为 \(d\) 的子序列，末尾接上 \(i\) 后仍为等差数列； - \(+1\)：\(j\) 和 \(i\) 两个元素本身构成一个长度为2的新等差数列。

    答案¶

    所有 \(f[i][d]\) 的总和，再加上 \(n\)（单个元素的合法情况）。

    复杂度¶

    时间：\(O(n^2)\)，空间：\(O(n \times V)\)（\(V\) 为公差范围）

    关键细节与技巧¶

    1. 偏移处理负公差：公差可能为负数，通过加上固定偏移量（如20000）将数组下标转为非负；
    2. 边转移边累加答案，无需最后再遍历整个DP数组；
    3. 全程取模，避免数值溢出。

    核心代码片段¶

    const int M = 20000; // 公差偏移量
ll f[N][M * 2 + 10];
ll ans = n; // 单个元素的情况
for (int i = 1; i <= n; ++i) {
    for (int j = 1; j < i; ++j) {
        int d = h[i] - h[j];
        f[i][d + M] = (f[i][d + M] + f[j][d + M] + 1) % MOD;
        ans = (ans + f[j][d + M] + 1) % MOD;
    }
}

    C [SDOI2010] 地精部落¶

    题型¶

    波动排列计数DP / 组合数递推

    题意¶

    求长度为 \(n\) 的波动排列（也叫摆动序列，每个元素要么比左右都大，要么比左右都小）的总个数，结果对 \(p\) 取模。

    核心思路¶

    利用波动排列的对称性与可拆分性，通过组合数将大问题拆分为左右子问题，递推求解。

    DP状态定义¶

    • \(f[i]\)：长度为 \(i\)、首项为峰的波动排列的方案数。

    转移方程¶

    枚举左侧子序列长度 \(j\)（必须为奇数，保证峰谷结构正确）： $\(f[i] = \sum_{j\text{ 为奇数}} C(i-1,\ j) \times f[j] \times f[i-1-j]\)$ 含义：从 \(i-1\) 个元素中选 \(j\) 个构成左侧波动序列，剩余构成右侧波动序列，组合相乘得到总方案。

    最终答案¶

    首项为峰和首项为谷的情况对称，因此答案为 \(f[n] \times 2 \bmod p\)。

    复杂度¶

    时间：\(O(n^2)\)，空间：\(O(n)\)（滚动数组优化组合数）

    关键细节与技巧¶

    1. 滚动数组求组合数：模数 \(p\) 不一定是质数，无法用逆元，因此用杨辉三角递推；通过 i &1 滚动优化，空间从 \(O(n^2)\) 降至 \(O(n)\)；
    2. 利用对称性只计算一种开头的情况，最后乘2，减少一半计算量；
    3. 边界：\(f[0] = f[1] = 1\)。

    核心代码片段¶

    ll c[2][N], f[N];
c[0][0] = 1;
f[0] = f[1] = 1;
for (int i = 2; i <= n; ++i) {
    // 滚动更新第i行组合数
    for (int j = 1; j <= i; ++j)
        c[i&1][j] = (c[i&1^1][j-1] + c[i&1^1][j]) % p;
    // 递推f[i]
    for (int j = 0; j < i; ++j)
        if (j & 1)
            f[i] = (f[i] + c[i&1^1][j] * f[j] % p * f[i-1-j]) % p;
}
cout << f[n] * 2 % p << '\n';

    D [HAOI2011] problem a¶

    题型¶

    带权区间调度转化题 / 线性DP

    题意¶

    \(n\) 个人参加考试，第 \(i\) 个人声称“有 \(a_i\) 个人分数比我高，\(b_i\) 个人分数比我低”，求最少有几个人说谎。

    核心思路¶

    问题转化：说谎最少等价于说真话的人最多。 - 一个人的陈述若为真，则他的排名区间为 \([a_i+1,\ n-b_i]\)，同区间内的人分数相同； - 多个相同区间的陈述，最多有 \(r-l+1\) 个人说真话（区间总人数）； - 问题最终转化为经典带权区间调度：选出若干不重叠的区间，最大化权值和。

    DP状态定义¶

    将所有区间按终点升序排序后，\(dp[i]\) 表示考虑前 \(i\) 个区间，能选出的最大真话人数。

    转移方程¶

    $\(dp[i] = \max(dp[i-1],\ dp[\text{prev}[i]] + w_i)\)$ - \(\text{prev}[i]\)：最后一个与第 \(i\) 个区间不相交的区间编号（终点 < 当前区间起点），通过二分查找得到； - \(w_i\)：第 \(i\) 个区间的权值，即该区间的陈述人数，最多不超过区间长度。

    答案¶

    \(n - dp[\text{cnt}]\)（总人数减去最多真话人数，即为最少说谎人数）

    复杂度¶

    时间：\(O(n \log n)\)，空间：\(O(n)\)

    关键步骤与细节¶

    1. 过滤无效区间：若 \(a_i + b_i \ge n\)，必然说谎，直接跳过；
    2. 区间去重合并：相同左右端点的区间合并，权值取 min(陈述人数, 区间长度)；
    3. 按终点升序排序，二分查找前驱区间，完成DP转移；
    4. 端点判定：本题中区间端点重合算相交，因此二分条件为 终点 < 起点。

    核心代码片段¶

    // 二分查找前驱区间
int l = 1, r = i - 1, prev = 0;
while (l <= r) {
    int mid = (l + r) / 2;
    if (s[mid].r < s[i].l) {
        prev = mid;
        l = mid + 1;
    } else r = mid - 1;
}
dp[i] = max(dp[i-1], dp[prev] + s[i].w);

    E [ZJOI2010] 排列计数¶

    题型¶

    树形DP / 组合计数 / Lucas定理

    题意¶

    求 \(1 \sim n\) 的排列中，满足小根堆性质（对任意 \(i\)，有 \(a_i < a_{2i}\) 且 \(a_i < a_{2i+1}\)）的排列个数，结果对质数 \(p\) 取模。

    核心思路¶

    完全二叉树结构下，根节点必须是最小值；左右子树分别也是小根堆，通过组合数分配左右子树的元素，从叶子到根递推求解。

    DP状态定义¶

    • \(sz[i]\)：以 \(i\) 为根的子树的节点总数；
    • \(f[i]\)：以 \(i\) 为根的子树，满足小根堆性质的排列方案数。

    转移方程¶

    $\(f[i] = C(sz[i]-1,\ sz[l]) \times f[l] \times f[r] \pmod{p}\)$ 含义：根节点放最小值，从剩余 \(sz[i]-1\) 个元素中选 \(sz[l]\) 个放入左子树，剩余放入右子树，左右子树各自独立满足小根堆性质。

    预处理¶

    1. 从 \(n\) 到 1 倒序计算每个节点的子树大小 \(sz[i]\)；
    2. 预处理阶乘与逆元，由于 \(n\) 可能大于模数 \(p\)，使用 Lucas定理 求解组合数。

    答案¶

    \(f[1] \bmod p\)

    复杂度¶

    预处理阶乘：\(O(\min(n, p))\)，递推 + \(Lucas\)：\(O(n \log n)\)

    关键细节与技巧¶

    1. 完全二叉树性质：节点 \(i\) 的左右儿子编号为 \(2i\) 和 \(2i+1\)；
    2. 当 \(n \ge p\) 时，\(n!\) 包含因子 \(p\)，普通逆元法失效，必须用Lucas定理拆分计算组合数；
    3. 从叶子节点向根节点倒序递推，保证计算父节点时子节点已计算完毕。

    核心代码片段¶

    // 计算子树大小
for (int i = n; i >= 1; --i) {
    sz[i] = 1;
    if (2*i <= n) sz[i] += sz[2*i];
    if (2*i+1 <= n) sz[i] += sz[2*i+1];
}
// 递推方案数
for (int i = n; i >= 1; --i) {
    f[i] = 1;
    int l = 2*i, r = 2*i+1;
    if (l <= n) {
        ll c = lucas(sz[i]-1, sz[l]);
        f[i] = c * f[l] % p;
        if (r <= n) f[i] = f[i] * f[r] % p;
    }
}

    H [COCI 2016/2017 #3] Zoltan 详细笔记¶

    一、题目大意¶

    给定长度为 \(n\) 的序列，按顺序依次将每个数字放在当前序列的最左侧或最右侧，最终得到一个新序列。求两个问题： 1. 所有可构造的新序列中，最长严格上升子序列（LIS）的最大长度； 2. 所有构造方式下，长度达到最大值的LIS的总个数，结果对 \(10^9+7\) 取模。

    二、核心问题转化（本题最难点！！！）¶

    这是本题的思维突破点，也是最关键的结论： 所有可构造出的序列，其结构必然满足：存在一个“中心元素”，中心左侧的元素原始下标单调递减，中心右侧的元素原始下标单调递增。

    等价转化：

    最终序列的任意一个LIS，都可以对应回原序列：以某个元素 \(i\) 为公共交点，左侧是原序列中以 \(i\) 开头的严格下降子序列（翻转后变为上升），右侧是原序列中以 \(i\) 开头的严格上升子序列，两部分拼接后整体严格递增。

    通俗理解：我们从原序列中抽出一个下降子序列，翻转后拼在左边，再接上一个上升子序列拼在右边，就能得到构造序列中的一个上升子序列；反之，任意构造序列的LIS也一定能拆成这样的两部分。

    三、最长LIS长度求解¶

    1. 状态定义¶

    • up[i]：以第 \(i\) 个元素开头的最长严格上升子序列长度（对应拼接的右半部分）
    • down[i]：以第 \(i\) 个元素开头的最长严格下降子序列长度（对应拼接的左半部分，翻转后变为上升）

    2. 长度计算公式¶

    枚举每个元素 \(i\) 作为拼接的公共交点，最长LIS的最大长度为： $\(\boldsymbol{ans\_len = \max_{1\le i\le n} \big( up[i] + down[i] - 1 \big)}\)$ 减 \(1\) 是因为元素 \(i\) 被上升、下降两个子序列各计算了一次，存在重复。

    四、总方案数推导¶

    1. 单个交点的LIS方案数¶

    定义配套计数数组： - cnt_up[i]：以 \(i\) 开头、长度恰好为 up[i] 的严格上升子序列的方案数 - cnt_down[i]：以 \(i\) 开头、长度恰好为 down[i] 的严格下降子序列的方案数

    对于确定的交点 \(i\)，能构成的最长LIS的方案数为两部分独立相乘： $\(ways_i = cnt\_up[i] \times cnt\_down[i]\)$

    2. 剩余元素的放置方案¶

    对于总长度为 \(ans\_len\) 的最长LIS，剩余 \(n - ans\_len\) 个元素不参与LIS，每个元素都可以自由选择放在最终序列的左侧或右侧，不影响最长LIS的长度。

    详细论证两种情况，最终结论统一： - 情况1：交点i是原序列第一个元素：剩余 \(n-ans\_len\) 个元素都有插左、插右2种选择，共 \(2^{n-ans\_len}\) 种放置方式。 - 情况2：交点i不是原序列第一个元素：剩余非LIS元素各有2种选择；同时交点i作为拼接接口，既可以归到左半部分翻转，也可以归到右半部分，同样多了2倍选择，最终总放置方案仍为 \(2^{n-ans\_len}\)。

    综上，每个符合条件的交点 \(i\) 对总方案的贡献为： $\(ways_i \times 2^{n - ans\_len}\)$

    3. 最终总方案数¶

    将所有满足 \(up[i]+down[i]-1 = ans\_len\) 的交点的贡献相加，即为最终总方案数。

    五、算法优化与实现¶

    1. 方向转化：开头型 → 结尾型¶

    我们更熟悉“以i结尾”的LIS求解，因此将原数组反转： - 反转数组的LIS → 对应原数组从后往前的上升 → 原数组“以i开头的下降子序列” - 反转数组的LDS → 对应原数组从后往前的下降 → 原数组“以i开头的上升子序列”

    2. 数据结构优化转移¶

    \(O(n^2)\) 的暴力DP无法通过大数据，用 线段树（或树状数组） 优化转移，时间复杂度降为 \(O(n\log n)\)： 1. 数值离散化：对原数组去重排序，压缩值域范围； 2. 线段树节点设计：每个节点维护两个信息——当前值域区间内的最长子序列长度、对应最长长度的方案数之和； 3. 合并规则：两个区间合并时，取长度更大的一方；长度相等则方案数相加； 4. 转移方式：遍历到第i个元素时，查询前缀/后缀的最优值，计算当前dp值后再插入线段树更新。

    3. 预处理¶

    • 预处理2的幂次数组 pow2，方便快速计算 \(2^{n-ans\_len}\)。

    六、关键细节与易错点¶

    1. 严格性判定：题目要求严格上升/下降，查询边界注意是 < 而非 <=，避免相等数值错误转移。
    2. 离散化去重：必须对数值去重，否则值域压缩不准确，线段树查询会出错。
    3. 方案数边界：查询结果长度为0时，方案数默认为1（对应只选当前元素一个的情况）。
    4. 解法限制：不能用“贪心+二分”的LIS解法，该方法无法统计方案数，必须用DP+数据结构优化。
    5. 取模规范：所有乘法、加法操作全程取模，变量使用 long long 防止溢出。

    七、解题步骤速记¶

    1. 转化问题：构造序列的LIS = 原序列下降子序列 + 上升子序列，交于一点；
    2. 反转数组，用线段树分别求出以每个元素开头的最长上升/下降子序列的长度与方案数；
    3. 枚举每个交点，计算最大长度与对应总方案数；
    4. 总方案数乘以 \(2^{n-ans\_len}\)，得到最终答案。

    Summary¶

    1. 线性DP的常见优化方向¶

    • 状态拆分优化：如绝世好题按二进制位拆分状态，把O(n²)降为O(n×32)；
    • 数据结构优化：如LIS类问题用线段树/树状数组，把O(n²)降为O(n log n)；
    • 滚动数组优化：如地精部落的组合数递推，把二维空间降为一维。

    2. 常见转化思想¶

    • 问题转化：如problem a将“最少说谎”转化为“最多真话”，再转化为带权区间调度；
    • 数组反转转化：将“以i开头”的DP转化为“以i结尾”的DP，复用成熟的解题模板。

    3. 计数类DP通用注意点¶

    • 边界初始化要准确（空集、单个元素的方案数）；
    • 模数全程取模，避免溢出；
    • 优先利用对称性，大幅减少计算量。
