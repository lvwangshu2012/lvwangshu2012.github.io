    动态 DP（DDP）¶

    前置知识：矩阵乘法、树链剖分、线段树、树形 DP
    适用场景：树上带修改的 DP 问题、序列带修改的 DP 问题

    0. 引入与概述¶

    什么是动态 DP¶

    动态 DP（Dynamic Dynamic Programming，简称 DDP）是一种用于解决 带修改操作的动态规划问题 的黑科技算法。由猫锟在 WC2018 首次系统介绍。

    传统 DP 只能处理静态问题——数据不变时计算一次答案。但如果数据会被修改（比如修改树上一个点的权值），每次修改后重新做一遍 DP 时间复杂度太高。

    动态 DP 的核心思想：将 DP 转移方程转化为 广义矩阵乘法 的形式，然后用数据结构（线段树 / 树链剖分）维护矩阵的区间乘积，从而支持快速修改和查询。

    典型应用场景¶

    问题 静态做法 动态 DP 做法
    序列最大子段和（带修改） 线段树维护 4 个值 广义矩阵 + 线段树
    树的最大权独立集（带点权修改） 树形 DP 树链剖分 + 矩阵 + 线段树
    树的最小权覆盖集（带约束查询） 树形 DP + 倍增 动态 DP
    树上带修改的计数类 DP 树形 DP 动态 DP

    1. 广义矩阵乘法¶

    为什么需要广义矩阵¶

    普通矩阵乘法定义为：

    \[ C_{i,j} = \sum_{k} A_{i,k} \times B_{k,j} \]

    但很多 DP 转移中不是乘法和加法，而是加法和取 max / min。我们需要一种新的"矩阵乘法"来适配这些 DP 转移。

    定义：max-plus 矩阵乘法¶

    将普通矩阵乘法中的：

    • 加法（+）替换为 取最大值（max）
    • 乘法（×）替换为 加法（+）

    得到：

    \[ C_{i,j} = \max_{k}(A_{i,k} + B_{k,j}) \]

    这就是 max-plus 矩阵乘法，也叫热带半群（tropical semiring）上的矩阵乘法。

    类似地，还有 min-plus 矩阵乘法：

    \[ C_{i,j} = \min_{k}(A_{i,k} + B_{k,j}) \]

    结合律¶

    广义矩阵乘法同样满足 结合律：

    \[ (A \times B) \times C = A \times (B \times C) \]

    证明思路：展开后两边都是对所有路径取 max + 求和，与顺序无关。

    正因为满足结合律，我们才能用线段树维护区间乘积，支持快速修改和查询。

    单位矩阵¶

    普通矩阵乘法的单位矩阵是对角线为 1、其余为 0 的矩阵。

    对于 max-plus 矩阵乘法，单位矩阵（幺元）是：

    • 对角线元素为 0（因为 x + 0 = x）
    • 其余元素为 -∞（因为 max(x, -∞) = x）
    \[ I = \begin{bmatrix} 0 & -\infty & -\infty \\ -\infty & 0 & -\infty \\ -\infty & -\infty & 0 \end{bmatrix} \]

    对于 min-plus 矩阵乘法，单位矩阵是：

    • 对角线元素为 0
    • 其余元素为 +∞

    代码实现¶

    const int INF = 0x3f3f3f3f;

struct Matrix {
    int g[2][2];  // 一般是 2×2 或 3×3

    Matrix() {
        memset(g, -0x3f, sizeof(g));
    }

    // max-plus 矩阵乘法
    Matrix operator*(const Matrix& b) const {
        Matrix res;
        for (int i = 0; i < 2; i++)
            for (int k = 0; k < 2; k++)
                for (int j = 0; j < 2; j++)
                    res.g[i][j] = max(res.g[i][j], g[i][k] + b.g[k][j]);
        return res;
    }
};

    注意循环顺序：i-k-j 的顺序比 i-j-k 快，因为前者对缓存更友好。

    2. 线性动态 DP（序列上的 DDP）¶

    在介绍树上动态 DP 之前，先看更简单的序列上的动态 DP，帮助理解核心思想。

    例题：最大子段和（带修改）¶

    题意：给定长度为 \(n\) 的序列，支持两种操作：

    1. 修改某个位置的值
    2. 查询区间 \([l, r]\) 的最大子段和

    静态 DP：设 \(f_i\) 为前 \(i\) 个数的最大子段和，\(g_i\) 为以 \(i\) 结尾的最大子段和。

    转移方程：

    \[ \begin{cases} g_i = \max(g_{i-1} + a_i,\ a_i) \\ f_i = \max(f_{i-1},\ g_i) \end{cases} \]

    转化为矩阵形式¶

    为了写成矩阵乘法，我们把状态写成列向量：

    \[ \begin{bmatrix} f_i \\ g_i \\ 0 \end{bmatrix} \]

    然后构造转移矩阵 \(M_i\)，使得：

    \[ \begin{bmatrix} f_i \\ g_i \\ 0 \end{bmatrix} = M_i \times \begin{bmatrix} f_{i-1} \\ g_{i-1} \\ 0 \end{bmatrix} \]

    展开验证：

    • \(f_i = \max(f_{i-1},\ g_{i-1} + a_i,\ a_i)\)
    • \(g_i = \max(-\infty,\ g_{i-1} + a_i,\ a_i)\)
    • \(0 = \max(-\infty,\ -\infty,\ 0)\)

    构造出的矩阵：

    \[ M_i = \begin{bmatrix} 0 & a_i & a_i \\ -\infty & a_i & a_i \\ -\infty & -\infty & 0 \end{bmatrix} \]

    验证：第一行的 max 运算对应 \(f_i = \max(f_{i-1}+0,\ g_{i-1}+a_i,\ 0+a_i)\)，与转移方程一致。

    这样，区间 \([l, r]\) 的转移就是所有矩阵的乘积：

    \[ M_{l..r} = M_l \times M_{l+1} \times \cdots \times M_r \]

    用线段树维护矩阵区间乘积，每次修改就是单点更新，每次查询就是区间矩阵乘，时间复杂度都是 \(O(\log n \times k^3)\)，其中 \(k\) 是矩阵大小（这里是 3）。

    模板¶

    #include <bits/stdc++.h>
using namespace std;

const int N = 50005;
const int INF = 0x3f3f3f3f;

int n, q;
int a[N];

struct Matrix {
    int g[3][3];
    Matrix() { memset(g, -0x3f, sizeof(g)); }

    Matrix operator*(const Matrix& b) const {
        Matrix res;
        for (int i = 0; i < 3; i++)
            for (int k = 0; k < 3; k++)
                for (int j = 0; j < 3; j++)
                    res.g[i][j] = max(res.g[i][j], g[i][k] + b.g[k][j]);
        return res;
    }
} tr[N << 2];

// 根据 a[pos] 构造矩阵
void build_node(int u, int pos) {
    tr[u].g[0][0] = 0;
    tr[u].g[0][1] = tr[u].g[0][2] = a[pos];
    tr[u].g[1][1] = tr[u].g[1][2] = a[pos];
    tr[u].g[2][2] = 0;
}

void build(int u, int l, int r) {
    if (l == r) {
        build_node(u, l);
        return;
    }
    int mid = (l + r) >> 1;
    build(u << 1, l, mid);
    build(u << 1 | 1, mid + 1, r);
    tr[u] = tr[u << 1] * tr[u << 1 | 1];
}

void modify(int u, int l, int r, int pos) {
    if (l == r) {
        build_node(u, pos);
        return;
    }
    int mid = (l + r) >> 1;
    if (pos <= mid) modify(u << 1, l, mid, pos);
    else modify(u << 1 | 1, mid + 1, r, pos);
    tr[u] = tr[u << 1] * tr[u << 1 | 1];
}

Matrix query(int u, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return tr[u];
    int mid = (l + r) >> 1;
    if (qr <= mid) return query(u << 1, l, mid, ql, qr);
    if (ql > mid) return query(u << 1 | 1, mid + 1, r, ql, qr);
    return query(u << 1, l, mid, ql, qr) * query(u << 1 | 1, mid + 1, r, ql, qr);
}

int main() {
    scanf("%d", &n);
    for (int i = 1; i <= n; i++)
        scanf("%d", &a[i]);
    build(1, 1, n);

    scanf("%d", &q);
    while (q--) {
        int op, x, y;
        scanf("%d%d%d", &op, &x, &y);
        if (op == 0) {  // 修改
            a[x] = y;
            modify(1, 1, n, x);
        } else {  // 查询 [x, y] 最大子段和
            Matrix res = query(1, 1, n, x, y);
            printf("%d\n", max(res.g[0][1], res.g[0][2]));
        }
    }
    return 0;
}

    3. 树上动态 DP（最大权独立集）¶

    树上动态 DP 是 DDP 最经典的应用。以 最大权独立集 为例，这也是洛谷 P4719 的模板题。

    题意回顾¶

    给定一棵 \(n\) 个点的树，点带权。有 \(m\) 次操作：

    • 修改点 \(x\) 的权值为 \(y\)
    • 查询整棵树的最大权独立集的权值大小

    静态 DP 回顾¶

    设 \(f_{u,0}\) 表示不选 \(u\) 时，以 \(u\) 为根的子树的最大权独立集；\(f_{u,1}\) 表示选 \(u\) 时的最大值。

    转移方程：

    \[ \begin{cases} f_{u,0} = \sum_{v \in son(u)} \max(f_{v,0},\ f_{v,1}) \\ f_{u,1} = w_u + \sum_{v \in son(u)} f_{v,0} \end{cases} \]

    答案为 \(\max(f_{root,0},\ f_{root,1})\)。

    从多儿子到单儿子：轻重链剖分¶

    轻重链剖分¶

    前置定义¶

    给定一棵有根树 \((T=(V,E))\)，根为 \(\mathit{(\mathit{root})}\)，对 \(\forall u\in V\)：

    1. \(\mathit{subtree}(u)\)：以 \(u\) 为根的子树点集；
    2. \(\mathit{size}(u) = |\mathit{subtree}(u)|\)：子树大小；
    3. \(\mathit{fa}(u)\)：\(u\) 的父节点；
    4. \(\mathit{dep}(u)\)：\(u\) 的深度；

    1. 重儿子、轻儿子¶

    设节点 \(u\) 的子节点集合为 \(\mathit{child}(u)\)。

    • 重儿子 \(\mathit{son}(u)\)：若存在 \(v\in \mathit{child}(u)\)，满足
    \[ \mathit{size}(v)=\max_{x\in\mathit{child}(u)}\mathit{size}(x) \]

    任选其一（一般取第一个满足的）称为 \(u\) 的重儿子；
    若 \(u\) 无孩子，则 \(\mathit{son}(u)=\emptyset\)（记为 \(0\)）。

    • 轻儿子：\(u\) 所有不是重儿子的子节点。

    2. 重边、轻边¶

    对边 \(e=(u,v)\)，其中 \(u=\mathit{fa}(v)\)：

    • 若 \(v=\mathit{son}(u)\)，称 \(e\) 为重边；
    • 否则称 \(e\) 为轻边。

    3. 重链（链划分）¶

    重链：极大路径，路径上所有相邻边均为重边。
    极大含义：不能再向两端延长且保持全部为重边。
    性质推论：

    1. 每个节点恰好属于一条重链；
    2. 一条重链存在唯一顶端节点 \(\mathit{top}(u)\)：
      链内深度最小的节点；
    3. 轻边一定连接两条不同重链的顶端。

    树状 DP 中一个点可能有多个儿子，这不利于写成矩阵转移。

    关键技巧：使用 树链剖分（重链剖分），将儿子分为 重儿子 和 轻儿子。

    定义：

    • \(son_u\) 表示 \(u\) 的重儿子
    • \(g_{u,0}\) 表示不选 \(u\) 时，只考虑轻儿子的最大答案
    • \(g_{u,1}\) 表示选 \(u\) 时，只考虑轻儿子的最大答案

    即：

    \[ \begin{cases} g_{u,0} = \sum_{v \in \text{轻儿子}} \max(f_{v,0},\ f_{v,1}) \\ g_{u,1} = w_u + \sum_{v \in \text{轻儿子}} f_{v,0} \end{cases} \]

    那么加上重儿子后的 DP 值为：

    \[ \begin{cases} f_{u,0} = g_{u,0} + \max(f_{son_u, 0},\ f_{son_u, 1}) \\ f_{u,1} = g_{u,1} + f_{son_u, 0} \end{cases} \]

    构造转移矩阵¶

    将上面的转移写成 max-plus 矩阵乘法：

    \[ \begin{bmatrix} f_{u,0} \\ f_{u,1} \end{bmatrix} = \begin{bmatrix} g_{u,0} & g_{u,0} \\ g_{u,1} & -\infty \end{bmatrix} \times \begin{bmatrix} f_{son_u, 0} \\ f_{son_u, 1} \end{bmatrix} \]

    验证展开：

    • \(f_{u,0} = \max(g_{u,0} + f_{son_u,0},\ g_{u,0} + f_{son_u,1}) = g_{u,0} + \max(f_{son_u,0}, f_{son_u,1})\) ✓
    • \(f_{u,1} = \max(g_{u,1} + f_{son_u,0},\ -\infty + f_{son_u,1}) = g_{u,1} + f_{son_u,0}\) ✓

    这样，一条重链上的转移就可以表示为矩阵的乘积。链顶的 DP 值等于链上所有矩阵的"乘积"再乘以链底的初始向量。

    数据结构维护¶

    用线段树维护每条重链上的矩阵区间乘积。

    • 对于每条重链，链底到链顶的矩阵乘积就是该链的转移矩阵
    • 修改一个点时，只影响该点所在重链以及所有祖先重链（因为轻边的贡献变了）
    • 每次往上跳一条重链，更新链顶父亲的 \(g\) 值

    修改过程¶

    修改点 \(x\) 的权值的步骤：

    1. 修改 \(x\) 处的矩阵：更新 \(g_{x,1}\)（因为点权在 \(g_1\) 里），更新线段树
    2. 跳重链：令 \(x = top(x)\)，计算修改前后链顶 DP 值的变化量
    3. 更新父亲：用变化量更新 \(fa_x\) 的 \(g\) 值（轻儿子贡献的变化）
    4. 重复：继续往上跳，直到根节点

    具体来说，当我们修改了一条重链后：

    • 设修改前链顶 \(t\) 的 DP 值为 \(old_0, old_1\)
    • 修改后链顶 \(t\) 的 DP 值为 \(new_0, new_1\)
    • 链顶的父亲 \(fa_t\) 的 \(g\) 值需要更新：
      • \(g_{fa_t, 0} += \max(new_0, new_1) - \max(old_0, old_1)\)
      • \(g_{fa_t, 1} += new_0 - old_0\)

    因为 \(t\) 是 \(fa_t\) 的轻儿子（否则 \(t\) 和 \(fa_t\) 在同一条重链上）。

    查询过程¶

    查询根节点所在重链的矩阵乘积，取 \(\max(f_{root,0}, f_{root,1})\) 即可。

    4. 完整模板：最大权独立集¶

    下面是洛谷 P4719【模板】动态 DP 的完整代码：

    #include <bits/stdc++.h>
using namespace std;

const int N = 1e5 + 5;
const int INF = 0x3f3f3f3f;

int n, m;
int w[N];
vector<int> G[N];

int fa[N], dep[N], sz[N], son[N];
int top[N], dfn[N], id[N], End[N];
int clk;

int f[N][2];  // f[u][0/1]: 子树内 u 不选/选 的最大权独立集
// g[u][0/1]: 只考虑轻儿子时，u 不选/选 的最大权独立集

struct Matrix {
    int g[2][2];
    Matrix() {
        memset(g, -0x3f, sizeof(g));
    }

    Matrix operator*(const Matrix& b) const {
        Matrix res;
        for (int i = 0; i < 2; i++)
            for (int k = 0; k < 2; k++)
                for (int j = 0; j < 2; j++)
                    res.g[i][j] = max(res.g[i][j], g[i][k] + b.g[k][j]);
        return res;
    }
} val[N]; 

Matrix tr[N << 2];

void pushup(int u) {
    tr[u] = tr[u << 1] * tr[u << 1 | 1];
}

void build(int u, int l, int r) {
    if (l == r) {
        tr[u] = val[id[l]];
        return;
    }
    int mid = (l + r) >> 1;
    build(u << 1, l, mid);
    build(u << 1 | 1, mid + 1, r);
    pushup(u);
}

void modify(int u, int l, int r, int pos) {
    if (l == r) {
        tr[u] = val[id[l]];
        return;
    }
    int mid = (l + r) >> 1;
    if (pos <= mid) modify(u << 1, l, mid, pos);
    else modify(u << 1 | 1, mid + 1, r, pos);
    pushup(u);
}

Matrix query(int u, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return tr[u];
    int mid = (l + r) >> 1;
    if (qr <= mid) return query(u << 1, l, mid, ql, qr);
    if (ql > mid) return query(u << 1 | 1, mid + 1, r, ql, qr);
    return query(u << 1, l, mid, ql, qr) * query(u << 1 | 1, mid + 1, r, ql, qr);
}

void dfs1(int u, int father) {
    fa[u] = father;
    dep[u] = dep[father] + 1;
    sz[u] = 1;
    f[u][1] = w[u];  // 选 u，初始权值

    for (int v : G[u]) {
        if (v == father) continue;
        dfs1(v, u);
        sz[u] += sz[v];
        if (sz[v] > sz[son[u]]) son[u] = v;
        // 累加所有儿子的贡献
        f[u][0] += max(f[v][0], f[v][1]);
        f[u][1] += f[v][0];
    }
}

void dfs2(int u, int t) {
    top[u] = t;
    dfn[u] = ++clk;
    id[clk] = u;
    End[t] = clk;  // 记录重链底端

    // 初始化 g 矩阵：只考虑轻儿子
    val[u].g[0][0] = val[u].g[0][1] = 0;  // g[u][0]
    val[u].g[1][0] = w[u];                 // g[u][1]
    val[u].g[1][1] = -INF;

    if (!son[u]) return;

    dfs2(son[u], t);  // 重儿子继续

    for (int v : G[u]) {
        if (v == fa[u] || v == son[u]) continue;
        dfs2(v, v);  // 轻儿子新开链
        // 累加轻儿子到 g 中
        val[u].g[0][0] += max(f[v][0], f[v][1]);
        val[u].g[0][1] = val[u].g[0][0];
        val[u].g[1][0] += f[v][0];
    }
}

void update(int x, int y) {
    val[x].g[1][0] += y - w[x];
    w[x] = y;

    while (x) {
        int t = top[x];
        // 修改前链顶的 DP 值
        Matrix old_mat = query(1, 1, n, dfn[t], End[t]);
        // 修改 x 处的矩阵
        modify(1, 1, n, dfn[x]);
        // 修改后链顶的 DP 值
        Matrix new_mat = query(1, 1, n, dfn[t], End[t]);

        x = fa[t];
        if (!x) break;

        // 更新父亲（t 是 x 的轻儿子）
        int old_max = max(old_mat.g[0][0], old_mat.g[1][0]);
        int new_max = max(new_mat.g[0][0], new_mat.g[1][0]);
        // g[x][0] += 变化量
        val[x].g[0][0] += new_max - old_max;
        val[x].g[0][1] = val[x].g[0][0];
        // g[x][1] += 变化量（不选 t 的情况）
        val[x].g[1][0] += new_mat.g[0][0] - old_mat.g[0][0];
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> n >> m;

    for (int i = 1; i <= n; i ++)
        cin >> w[i];

    for (int i = 1; i < n; i ++) {
        int u, v; cin >> u >> v;
        G[u].push_back(v);
        G[v].push_back(u);
    }

    dfs1(1, 0);
    dfs2(1, 1);
    build(1, 1, n);

    while (m --) {
        int x, y; cin >> x >> y;

        update(x, y);
        Matrix ans = query(1, 1, n, dfn[1], End[1]);
        cout << max(ans.g[0][0], ans.g[1][0]) << '\n';
    }

    return 0;
}

    5. 实现细节与注意事项¶

    矩阵乘法方向¶

    矩阵乘法的方向很重要，有两种写法：

    左乘（列向量）：

    \[ f_u = M_u \times f_{son} \]

    右乘（行向量）：

    \[ f_u = f_{son} \times M_u \]

    两种写法都可以，只要前后一致就行。一般左乘更直观，但右乘在某些问题中更方便。

    注意线段树合并时，左子树的矩阵要乘在右边。

    线段树的查询合并顺序¶

    由于矩阵乘法不满足交换律，线段树查询左右区间时，顺序不能反。

    对于左乘模型：

    • 左半区间的矩阵在前（更靠近链顶）
    • 右半区间的矩阵在后（更靠近链底）
    // dfn 序：链顶 -> 链底（从重儿子方向往下）
// 但转移方向是从链底向链顶，所以链底的矩阵要先乘
// 具体顺序需要仔细确认

    重点提醒：一定要搞清楚 dfn 序和转移方向的关系，否则矩阵乘法顺序反了会 WA 得很惨。建议手动推导小规模例子验证。

    INF 的取值¶

    • max-plus 矩阵：INF 应该足够小，用 -INF 表示不可达
    • min-plus 矩阵：INF 应该足够大，用 INF 表示不可达

    注意溢出问题：两个 INF 相加可能爆 int，要根据题目调整（用 long long 或设合适的 INF）。

    // 常见取值
const int INF = 0x3f3f3f3f;       // int: 约 1e9
const long long INFLL = 1e18;     // long long

    矩阵大小与常数¶

    矩阵一般是 2×2 或 3×3 的，所以 \(k^3\) 的常数很小（8 或 27）。

    • 2×2 矩阵乘法：8 次加法 + 8 次 max
    • 3×3 矩阵乘法：27 次加法 + 27 次 max

    整体时间复杂度：

    • 序列 DDP：\(O(m \log n \times k^3)\)
    • 树上 DDP：\(O(m \log^2 n \times k^3)\)（每次修改跳 \(\log n\) 条链，每条链线段树查询是 \(\log n\)）

    虽然是 \(O(m \log^2 n)\)，但常数很小，实际跑起来很快。

    初始化的坑¶

    • 矩阵初始值：所有位置设为 -INF（max-plus）或 +INF（min-plus）
    • 不要忘记对角线的单位元
    • 叶子节点（没有重儿子的点）的转移矩阵要特别处理

    6. 保卫王国（最小权覆盖集）¶

    题意¶

    NOIP2018 提高组 D2T3：给定一棵树，每个节点有驻军代价。一条边连接的两个点至少有一个要驻军。有 \(m\) 次询问，每次规定两个点必须/不能驻军，求此时的最小代价。

    转化¶

    最小权覆盖集 = 总权值 - 最大权独立集

    或者直接用 DP 做最小权覆盖集：

    设 \(f_{u,0}\) 表示 \(u\) 不选时的最小代价，\(f_{u,1}\) 表示 \(u\) 选时的最小代价。

    转移方程：

    \[ \begin{cases} f_{u,0} = \sum_{v \in son(u)} f_{v,1} \\ f_{u,1} = w_u + \sum_{v \in son(u)} \min(f_{v,0},\ f_{v,1}) \end{cases} \]

    用 min-plus 矩阵乘法：

    \[ C_{i,j} = \min_{k}(A_{i,k} + B_{k,j}) \]

    构造转移矩阵：

    \[ \begin{bmatrix} f_{u,0} \\ f_{u,1} \end{bmatrix} = \begin{bmatrix} +\infty & g_{u,0} \\ g_{u,1} & g_{u,1} \end{bmatrix} \times \begin{bmatrix} f_{son_u, 0} \\ f_{son_u, 1} \end{bmatrix} \]

    其中 \(g_{u,0/1}\) 是只考虑轻儿子的贡献。

    处理约束条件¶

    对于"必须选/必须不选"的约束，可以通过修改转移矩阵来实现：

    • 必须选 \(x\)：让 \(f_{x,0}\) 不可能（设为 \(+\infty\)），即修改矩阵使得不选的转移被堵死
    • 必须不选 \(x\)：让 \(f_{x,1}\) 不可能（设为 \(+\infty\)）

    具体来说：

    • 必须不选：\(g_{x,1} = +\infty\)（转移到选的路径被堵）
    • 必须选：将 \(g_{x,0}\) 设为 \(+\infty\)，只保留选的路径

    注意：每次询问独立，修改后要恢复。或者每次询问前存下原始值，询问后还原。

    7. 动态 DP 的通用构造方法¶

    面对一个新的 DP 问题，如何判断能不能用动态 DP，又如何构造矩阵？

    第一步：写出静态 DP 方程¶

    先写出不带修改的 DP 转移方程。如果是树形 DP，状态维度一般是 2~3 维。

    第二步：判断运算形式¶

    看转移方程中的运算是什么：

    外层运算 内层运算 矩阵类型
    max + max-plus
    min + min-plus
    + × 普通矩阵（模意义下）
    + + 普通加法（退化了）

    关键条件：外层运算对内层运算有 分配律。比如 max 对 + 有分配律：

    \[ \max(a+c, b+c) = c + \max(a, b) \]

    如果满足分配律，就可以构造广义矩阵乘法。

    第三步：树链剖分轻重分离（树上问题）¶

    将 DP 拆为重儿子部分和轻儿子部分：

    \[ f_u = g_u \otimes f_{son_u} \]

    其中 \(g_u\) 只包含轻儿子的贡献，\(\otimes\) 是广义矩阵乘法。

    第四步：构造转移矩阵¶

    将状态写成向量形式，然后根据转移方程反推矩阵元素。

    例如，对于 2 维状态 \([f_0, f_1]^T\)，要满足：

    \[ \begin{bmatrix} f'_0 \\ f'_1 \end{bmatrix} = \begin{bmatrix} m_{00} & m_{01} \\ m_{10} & m_{11} \end{bmatrix} \times \begin{bmatrix} f_0 \\ f_1 \end{bmatrix} \]

    展开对比系数，求出每个 \(m_{ij}\)。

    8. 拓展：LCT (动态树) 实现动态 DP¶

    除了树链剖分 + 线段树，还可以用 Link-Cut Tree（LCT） 实现动态 DP。

    思路¶

    LCT 的每个 splay 节点维护其子树内的矩阵乘积。access 操作会改变轻重边划分，同时更新矩阵信息。

    优缺点¶

    实现方式 时间复杂度 代码长度 常数
    树链剖分 + 线段树 \(O(\log^2 n)\) 较长 小
    LCT \(O(\log n)\) 很长 较大

    一般来说，树链剖分版本更常用，因为代码相对好写、常数小、不容易错。

    10. 总结与对比¶

    动态 DP vs 其他方法¶

    方法 适用场景 修改复杂度 代码难度
    重新 DP 数据量小、修改少 \(O(n)\) 低
    倍增 DP 树上约束查询（无修改） - 中
    动态 DP 带修改的 DP 问题 \(O(\log^2 n)\) 高
    线段树维护信息 序列简单问题 \(O(\log n)\) 中

    什么时候用动态 DP¶

    1. 树形 DP + 单点修改 —— 最经典的应用场景
    2. 序列 DP + 单点修改 —— 可以但有时线段树直接维护更简单
    3. DP 状态维度小（2~3 维）—— 矩阵常数小
    4. 转移满足分配律 —— max/min 对加法的分配律
