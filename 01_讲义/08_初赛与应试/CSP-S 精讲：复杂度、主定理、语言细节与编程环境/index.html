    CSP-S 精讲：复杂度、主定理、语言细节与编程环境¶

    优先级：Linux 命令 P0（4/5 年白送分）、主定理 P0（3/5 年）、C++ 语言细节 P1、编译环境 P1 读法：第三节主定理是本份核心，务必理解"递归树"的直觉；Linux 那节考前背一遍即可

    第一部分：复杂度分析基础¶

    1.1 三种渐进符号¶

    符号 含义 类比
    \(O\)（大 O） 上界（不超过） \(\le\)
    \(\Omega\)（大 Omega） 下界（不低于） \(\ge\)
    \(\Theta\)（大 Theta） 同阶（既是上界也是下界） \(=\)

    严格定义（了解）：

    • \(f(n) = O(g(n))\)：存在常数 \(c>0\) 和 \(n_0\)，使得对 all \(n > n_0\) 有 \(f(n) \le c\cdot g(n)\)
    • 其余同理

    实战：初赛说的"时间复杂度"一般指 \(O\) 或 \(\Theta\)，不必纠结。

    1.2 常见复杂度量级排序（从小到大）¶

    \(O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(n^3) < O(2^n) < O(n!) < O(n^n)\)

    记忆锚点：\(2^{10} = 1024 \approx 10^3\)，所以 \(\log_2 n\) 在 \(n = 10^6\) 时约为 20 —— 对数级增长极慢。

    \(n\) \(\log_2 n\) \(n\log_2 n\) \(n^2\) \(2^n\)
    10 3.3 33 100 1024
    \(10^3\) 10 \(10^4\) \(10^6\) 巨大
    \(10^5\) 17 \(1.7\times10^6\) \(10^{10}\) —
    \(10^6\) 20 \(2\times10^7\) \(10^{12}\) —

    经验法则（估算能否通过）：\(10^8\) 次简单运算 ≈ 1 秒。

    1.3 从代码结构直接读复杂度¶

    代码结构 复杂度
    无循环的赋值 \(O(1)\)
    for(i=0;i<n;i++) \(O(n)\)
    for(i=0;i<n;i*=2) \(O(\log n)\)
    两层独立 for 各 \(n\) 次 \(O(n^2)\)
    for(i){ for(j=0;j<i;j++) } \(O(n^2)\)（约 \(n^2/2\)）
    while(l<=r) 每次区间减半 \(O(\log n)\)
    递归 \(T(n)=T(n-1)+O(1)\) \(O(n)\)
    递归 \(T(n)=2T(n/2)+O(n)\) \(O(n\log n)\)

    ⚠️ 注意 for(i=0;i*i<n;i++) → 循环 \(\sqrt{n}\) 次 → \(O(\sqrt{n})\)。

    第二部分：主定理（Master Theorem）¶

    2.1 适用形式¶

    主定理用于求解形如下式的分治递归复杂度：

    \(T(n) = a\,T\!\left(\frac{n}{b}\right) + f(n)\)

    其中：

    • \(a \ge 1\)：每层递归产生的子问题个数
    • \(b > 1\)：每个子问题的规模缩小倍数
    • \(f(n)\)：分解与合并的额外开销

    2.2 递归树直觉（比背公式重要）¶

    把递归展开成一棵树：

    • 第 0 层（根）：1 个问题，规模 \(n\)，开销 \(f(n)\)
    • 第 1 层：\(a\) 个问题，每个规模 \(n/b\)，总开销 \(a \cdot f(n/b)\)
    • 第 \(k\) 层：\(a^k\) 个问题，每个规模 \(n/b^k\)，总开销 \(a^k \cdot f(n/b^k)\)
    • 叶子层：一共 \(\log_b n\) 层，叶子数 \(a^{\log_b n} = n^{\log_b a}\)

    记关键量：

    \(\boxed{c = \log_b a}\)

    则叶子层的总贡献是 \(\Theta(n^{c})\)，而根层贡献是 \(f(n)\)。

    主定理的本质：比较"根层开销 \(f(n)\)"和"叶子层开销 \(n^{c}\)"谁更大。

    谁更大 结果
    叶子层主导 \(T(n) = \Theta(n^{c})\)
    两者打平 每层都一样多 → 再乘层数 \(\log n\)
    根层主导 \(T(n) = \Theta(f(n))\)

    2.3 三种情形（严格表述）¶

    设 \(c = \log_b a\)：

    情形 条件 结论
    一 \(f(n) = O(n^{c-\varepsilon})\)，某 \(\varepsilon>0\) \(T(n) = \Theta(n^{c})\)
    二 \(f(n) = \Theta(n^{c})\) \(T(n) = \Theta(n^{c}\log n)\)
    三 \(f(n) = \Omega(n^{c+\varepsilon})\) 且满足正则条件 \(a\,f(n/b) \le k\,f(n)\)（某 \(k<1\)） \(T(n) = \Theta(f(n))\)

    大白话版本：

    • 情形一：\(f(n)\) 比 \(n^c\) 小一个多项式级 → 叶子说了算 → \(\Theta(n^c)\)
    • 情形二：\(f(n)\) 和 \(n^c\) 同阶 → 每层一样多，共 \(\log n\) 层 → \(\Theta(n^c \log n)\)
    • 情形三：\(f(n)\) 比 \(n^c\) 大一个多项式级 → 根说了算 → \(\Theta(f(n))\)

    2.4 五道例题（分步推导）¶

    例 1：\(T(n) = 2T(n/2) + O(n)\)（归并排序）

    • \(a=2, b=2\) → \(c = \log_2 2 = 1\)
    • \(f(n) = O(n) = \Theta(n^1) = \Theta(n^{c})\) → 情形二
    • \(T(n) = \Theta(n^{1}\log n) = \boxed{O(n\log n)}\)

    例 2：\(T(n) = 2T(n/2) + O(1)\)

    • \(a=2,b=2\) → \(c=1\)
    • \(f(n)=O(1)=\Theta(n^0)\)，而 \(n^{c}=n^1\) → \(f(n)\) 小一个量级 → 情形一
    • \(T(n) = \Theta(n^{1}) = \boxed{O(n)}\)

    例 3：\(T(n) = T(n/2) + O(1)\)（二分查找）

    • \(a=1,b=2\) → \(c = \log_2 1 = 0\)
    • \(f(n)=O(1)=\Theta(n^{0})=\Theta(n^{c})\) → 情形二
    • \(T(n) = \Theta(n^{0}\log n) = \boxed{O(\log n)}\)

    例 4：\(T(n) = 4T(n/2) + O(n)\)

    • \(a=4,b=2\) → \(c = \log_2 4 = 2\)
    • \(f(n) = O(n) = \Theta(n^1)\)，比 \(n^2\) 小 → 情形一
    • \(T(n) = \Theta(n^{2}) = \boxed{O(n^2)}\)

    例 5：\(T(n) = 2T(n/2) + O(n^2)\)

    • \(a=2,b=2\) → \(c=1\)
    • \(f(n)=O(n^2)\)，比 \(n^{1}\) 大一个量级 → 情形三（正则条件成立）
    • \(T(n) = \boxed{O(n^2)}\)

    2.5 常考递推式速查表¶

    递推式 复杂度 对应算法
    \(T(n)=T(n-1)+O(1)\) \(O(n)\) 线性扫描
    \(T(n)=T(n-1)+O(n)\) \(O(n^2)\) 选择排序
    \(T(n)=2T(n-1)+O(1)\) \(O(2^n)\) 汉诺塔、朴素斐波那契
    \(T(n)=T(n/2)+O(1)\) \(O(\log n)\) 二分查找
    \(T(n)=T(n/2)+O(n)\) \(O(n)\) 最坏快排的一次划分和
    \(T(n)=2T(n/2)+O(1)\) \(O(n)\) 遍历二叉树
    \(T(n)=2T(n/2)+O(n)\) \(O(n\log n)\) 归并/快排平均
    \(T(n)=2T(n/2)+O(n^2)\) \(O(n^2)\) 情形三

    2.6 主定理的失效情况（陷阱）¶

    主定理不适用当：

    1. \(f(n)\) 与 \(n^{c}\) 只差一个对数因子（如 \(f(n)=n^{c}\log n\)）——需要用扩展版本
    2. \(a\) 或 \(b\) 不是常数（如 \(T(n)=n\,T(n/2)\)）
    3. 子问题规模不相等（如 \(T(n)=T(n/3)+T(2n/3)\)）

    最经典的陷阱题：

    ll qpow(ll a, ll n) {
    if (n == 0) return 1;
    return qpow(a, n/2) * qpow(a, n/2);   // ← 调用了两次！
}
    • 虽然看起来像 \(T(n)=T(n/2)+O(1)\)，但递归调用了两次
    • 正确递推：\(T(n) = 2T(n/2) + O(1)\) → \(a=2,b=2,c=1\) → 情形一 → \(\boxed{O(n)}\)
    • 不是 \(O(\log n)\)！

    正确写法只调用一次：

    ll qpow(ll a, ll n) {
    if (n == 0) return 1;
    ll t = qpow(a, n/2);        // ← 只算一次
    return t * t * (n & 1 ? a : 1);
}

    → \(T(n) = T(n/2)+O(1) = O(\log n)\)

    另一个陷阱：朴素斐波那契 fib(n) = fib(n-1) + fib(n-2) → \(T(n) = T(n-1)+T(n-2)+O(1)\) → \(\boxed{O(2^n)}\)（实际是 \(O(\phi^n)\)，\(\phi\approx1.618\)，但初赛按 \(O(2^n)\) 估）。

    第三部分：C++ 语言细节¶

    3.1 运算符优先级（从高到低，常用部分）¶

    级别 运算符 说明
    1 :: 作用域
    2 ++ --（后缀）、()、[]、.、->
    3 ++ --（前缀）、!、~、+ -（一元）、*（解引用）、&（取址）、sizeof 单目
    4 * / % 算术
    5 + - 算术
    6 << >> 移位
    7 < <= > >= 关系
    8 == != 相等
    9 & 按位与
    10 ^ 按位异或
    11 \\| 按位或
    12 && 逻辑与
    13 \\|\\| 逻辑或
    14 ?: 三目
    15 = += 等 赋值
    16 , 逗号

    必记的三条：

    1. 移位 << >> 的优先级低于加减：1 << n + 1 等价于 1 << (n+1)，不是 (1<<n)+1
    2. 按位运算 & ^ | 的优先级低于 ==：x & 1 == 0 等价于 x & (1==0) = x & 0 = 0！必须写成 (x & 1) == 0
    3. & 高于 ^ 高于 |

    建议：位运算一律加括号，不要赌优先级。

    3.2 整数除法与截断¶

    C++ 整数除法向零截断（不是向下取整）：

    表达式 结果
    7 / 2 3
    -7 / 2 -3（向零截断，不是 -4）
    7 % 2 1
    -7 % 2 -1（符号跟被除数）

    求中位数防溢出写法：

    int mid = l + (r - l) / 2;   // 推荐：避免 l+r 溢出

    而非 int mid = (l + r) / 2;

    3.3 整型范围与溢出¶

    类型 字节 范围
    char 1 \(-128 \sim 127\)
    unsigned char 1 \(0 \sim 255\)
    short 2 \(\pm 3.28\times10^4\)
    unsigned short 2 \(0 \sim 65535\)
    int 4 \(\pm 2.147\times10^9\)
    unsigned int 4 \(0 \sim 4.29\times10^9\)
    long long 8 \(\pm 9.22\times10^{18}\)
    unsigned long long 8 \(0 \sim 1.84\times10^{19}\)

    溢出陷阱：

    int a = 1000000, b = 1000000;
long long c = a * b;    // ← 错！a*b 仍是 int，已溢出
long long c = 1LL * a * b;   // ← 对！先提升为 long long

    有符号溢出是未定义行为（UB），无符号溢出是模 \(2^{32}\) 回绕。

    3.4 大端序与小端序¶

    • 大端序（Big Endian）：高位字节存低地址（符合人类书写习惯）
    • 小端序（Little Endian）：低位字节存低地址（x86 / 常见 PC 是小端）

    例：int x = 0x12345678，起始地址 0x100：

    地址 大端 小端
    0x100 12 78
    0x101 34 56
    0x102 56 34
    0x103 78 12

    网络字节序是大端。

    3.5 栈溢出¶

    原因：递归层数过深，超出栈空间。

    默认栈大小：Linux 通常 8 MB，Windows 通常 1~2 MB。

    能递归多少层：每层开销约几十字节 → 大致 \(10^5\) 层左右就会爆栈。

    典型场景（2021T3、2024T3 考过）：

    • 朴素快速幂写成 \(O(n)\) 递归
    • 链表/树的深递归
    • 斐波那契 \(O(2^n)\) 递归（深度 \(n\)）

    4.3 编译与运行¶

    编译：

    g++ -o a a.cpp -O2 -std=c++14 -Wall
    选项 作用
    -o <file> 指定输出可执行文件名
    -O0 / -O1 / -O2 / -O3 优化级别（竞赛用 -O2）
    -std=c++11 / c++14 / c++17 C++ 标准
    -Wall 开启所有警告
    -g 带调试信息（配合 gdb）

    运行与计时：

    time ./a.out < in.txt > out.txt

    time 输出三个时间：

    名称 含义
    real 墙钟时间（从开始到结束的真实时间，含等待 I/O）
    user 用户态 CPU 时间
    sys 内核态 CPU 时间

    ⚠️ 常考：多核并行时 user + sys 可以大于 real。

    输入输出重定向：

    • < in.txt：从文件读输入
    • > out.txt：输出覆盖写入文件
    • >> out.txt：追加写入
    • 2> err.txt：错误输出重定向

    GDB 常用命令（了解）： run、break <行号>、next、step、print <变量>、continue、quit

    六、易错清单¶

    1. 1 << n + 1 = 1 << (n+1)（移位优先级低于加减）
    2. x & 1 == 0 是错的，必须 (x & 1) == 0
    3. int 相乘溢出：用 1LL * a * b
    4. 整数除法向零截断：-7/2 = -3 不是 -4
    5. 中位数用 l + (r-l)/2 防溢出
    6. 快速幂递归两次 → \(O(n)\) 不是 \(O(\log n)\)
    7. time 的三个时间：real / user / sys，多核时 user 可 > real
    8. rm -r 才能删目录
    9. 小端序：低位字节存低地址（x86）
    10. 递归约 \(10^5\) 层会爆栈

    七、自测（答案在最后）¶

    1. \(T(n) = 8T(n/2) + O(n^2)\) 的复杂度？
    2. \(T(n) = 3T(n/4) + O(n\log n)\) 的复杂度（提示：\(\log_4 3 \approx 0.79\)）？
    3. 表达式 2 << 1 + 1 的值是多少？
    4. -7 / 2 和 -7 % 2 各是多少？
    5. int a=50000, b=50000; a*b 的结果是多少（考虑溢出）？
    答案 1. $c=\log_2 8 = 3$；$f(n)=O(n^2)$ 比 $n^3$ 小一个量级 → **情形一** → $\Theta(n^{3}) = \mathbf{O(n^3)}$ 2. $c=\log_4 3 \approx 0.79$；$f(n)=O(n\log n) = \Omega(n^{0.79+\varepsilon})$（取 $\varepsilon < 0.21$）→ **情形三** → $\mathbf{O(n\log n)}$ 3. `+` 优先于 `<<` → `2 << (1+1)` = `2 << 2` = **8** 4. `-7/2 = -3`（向零截断），`-7%2 = -1`（符号跟被除数） 5. $50000 \times 50000 = 2.5\times10^9 > 2.147\times10^9$ → **溢出**，实际结果约为 $2.5\times10^9 - 2^{32} = -1794967296$
