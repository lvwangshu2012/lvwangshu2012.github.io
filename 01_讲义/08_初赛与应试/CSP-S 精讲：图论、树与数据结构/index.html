    CSP-S 精讲：图论、树与数据结构¶

    优先级：P0 —— 二叉树性质 4/5 年、哈希线性探查 4/5 年、排序稳定性 4/5 年、图论每年必考 读法：本模块以"概念辨析 + 手算模拟"为主。判定条件和计数方法是拿分点，算法实现过程不是

    第一部分：图论¶

    1.1 图的基本概念速查¶

    概念 定义
    度数 \(\deg(v)\) 与 \(v\) 相连的边数（有向图分入度、出度）
    握手定理 \(\sum \deg(v) = 2m\)（无向图，每条边贡献 2 度）
    完全图 \(K_n\) 任意两点有边，边数 \(C_n^2 = \frac{n(n-1)}{2}\)
    连通图 任意两点可达
    生成树 包含全部 \(n\) 点、\(n-1\) 条边的连通子图
    补图 原图没有的边构成的图

    推论（常考）：无向图中奇度顶点的个数必为偶数。

    1.2 欧拉图 —— "一笔画"¶

    类型 判定条件
    欧拉回路 图连通 且 所有顶点度数为偶数
    欧拉路径 图连通 且 奇度顶点恰为 0 个或 2 个
    非欧拉（半欧拉） 奇度顶点 > 2 个

    直觉：一笔画时，除起点和终点外，每个点"进去一次就得出来一次" → 度数为偶数。起点和终点若是不同点，这两个点可以是奇数度。

    常考题：给一个图问"能否一笔画" → 数奇度顶点个数。

    ⚠️ 注意：判定条件是"连通且度数为偶"，两个条件缺一不可。孤立点不影响，但图必须连通（对于有边相连的顶点集合）。

    1.3 哈密顿图 —— "每个点恰好经过一次"¶

    与欧拉图的区别（必考辨析）：

    欧拉 哈密顿
    经过对象 每条边恰好一次 每个点恰好一次
    判定 有简洁充要条件（度数） 无简洁充要条件（NP 完全）

    充分条件（了解即可）：

    • Dirac 定理：\(n \ge 3\) 且每个点度数 \(\ge n/2\) → 必有哈密顿回路
    • Ore 定理：任意两个不相邻点 \(u,v\) 满足 \(\deg(u)+\deg(v) \ge n\) → 必有哈密顿回路

    考试策略：哈密顿回路没有万能判定公式，只能手动构造或举反例。看到选项说"当且仅当……"基本是错的。

    1.4 二分图 —— "可二染色"¶

    等价条件（三个互相等价）：

    1. 顶点可分成两个集合，每条边的两端分属不同集合
    2. 不存在奇环（长度为奇数的环）
    3. 可用两种颜色染色，相邻点异色

    判定算法：BFS/DFS 二染色，遇到同色相邻 → 不是二分图。

    常见二分图：树（无环，必然二染色）、网格图（按棋盘黑白染色）、偶环。

    1.5 DAG 与拓扑排序¶

    DAG = 有向无环图。

    拓扑序：顶点的一个线性排列，使得对每条有向边 \((u,v)\)，\(u\) 都排在 \(v\) 前面。

    存在条件：图无环（有环则无拓扑序）。

    拓扑序的数量（2025 年考过）：

    ⚠️ 没有只依赖 \(n\) 和 \(m\) 的通用公式！ 数量完全取决于图的具体结构。

    图结构 拓扑序数量
    空图（无边） \(n!\)
    链（\(n-1\) 条边串成一条） 1
    星形（中心指向其余 \(n-1\) 个点） \((n-1)!\)
    若干条不相连的链（长度 \(l_1,l_2,\ldots\)） \(\dfrac{(l_1+l_2+\cdots)!}{l_1!\,l_2!\cdots}\)

    例题（2025 T5）：DAG 的拓扑排序结果有多少种？选项 A.只有1种 B.最多n种 C.等于 \(n-m\) 种 D.以上都不对 → 反例：\(m=0\) 时有 \(n!\) 种（排除 A、B）；链时 1 种但 \(n-m=1\)，而 \(n=4,m=2\) 的星形有 6 种但 \(n-m=2\)（排除 C）→ 答案 D

    1.6 平面图¶

    欧拉公式（连通平面图）： $ $n - m + f = 2 $ 其中 n\(顶点数、\)m$ 边数、$f $ 面数（含外部无穷面）。

    边数上界（\(n \ge 3\) 的简单连通平面图）： \(m \le 3n - 6\)

    用途：证明某图不是平面图。例如 \(K_5\)：\(n=5, m=10\)，而 \(3n-6 = 9\)，\(10 > 9\) → \(K_5\) 非平面图。

    1.7 最小生成树（MST）¶

    算法 思想 复杂度 适用
    Prim 从一个点出发，每次加距离最小的点 \(O(n^2)\) 或 \(O(m\log n)\) 稠密图
    Kruskal 边按权排序，依次加不成环的边（用并查集） \(O(m\log m)\) 稀疏图

    性质：

    • MST 的边数一定是 \(n-1\)
    • 若所有边权不同，MST 唯一
    • MST 的权值总和最小，但不一定任意两点间路径最短（那是「最小生成树 vs 最短路」的经典辨析陷阱）

    1.8 最短路¶

    算法 适用 复杂度 负权
    BFS 无权图 \(O(n+m)\) —
    Dijkstra 非负权 \(O((n+m)\log n)\) ❌ 不支持
    Bellman-Ford 任意 \(O(nm)\) ✅ 支持，可判负环
    SPFA 任意 均摊 \(O(km)\) ✅
    Floyd 全源 \(O(n^3)\) ✅

    Dijkstra 手算步骤（考过）：

    1. 初始化 \(d[s]=0\)，其余 \(d=\infty\)
    2. 每轮取未确定的 \(d\) 最小的点 \(u\)，标记确定
    3. 用 \(u\) 松弛所有邻点：\(d[v] = \min(d[v],\, d[u]+w(u,v))\)
    4. 重复 \(n\) 轮

    ⚠️ Dijkstra 不能处理负权边——这是最常见的辨析陷阱。

    第二部分：树¶

    2.1 树的等价定义（六个说法一回事）¶

    对于 \(n\) 个顶点的无向图，以下等价：

    1. 连通且无环
    2. 连通且有 \(n-1\) 条边
    3. 无环且有 \(n-1\) 条边
    4. 任意两点间有唯一简单路径
    5. 连通，但删去任一条边后不连通
    6. 无环，但添加任一条边后恰有一个环

    2.2 二叉树必记公式¶

    项 公式
    第 \(i\) 层最多结点数（根为第 1 层） \(2^{i-1}\)
    深度为 \(h\) 的二叉树最多结点数 \(2^{h} - 1\)
    \(n\) 个结点的完全二叉树深度 \(\lfloor\log_2 n\rfloor + 1\)
    叶子数 \(n_0\) 与度为 2 的结点数 \(n_2\) \(\boxed{n_0 = n_2 + 1}\)
    二叉树总结点 \(n = n_0 + n_1 + n_2\)

    完全二叉树编号（1-based）：

    • 结点 \(i\) 的左孩子：\(2i\)；右孩子：\(2i+1\)
    • 结点 \(i\) 的父结点：\(\lfloor i/2 \rfloor\)
    • 若 \(2i > n\)，则 \(i\) 是叶子

    满二叉树 vs 完全二叉树：

    • 满二叉树：每层都满（结点数 \(2^h-1\)）
    • 完全二叉树：只有最后一层可能不满，且结点靠左连续

    2.3 三种遍历¶

    遍历 顺序 记忆
    前序（先序） 根 → 左 → 右 根在最前
    中序 左 → 根 → 右 根在中间
    后序 左 → 右 → 根 根在最后

    重建二叉树（2025 T8 考过）：

    给定 能否唯一重建
    中序 + 前序 ✅ 能
    中序 + 后序 ✅ 能
    前序 + 后序 ❌ 不能（无法区分左右子树）

    为什么：中序用来确定"哪些点在左子树、哪些在右子树"，前序或后序用来确定"根是谁"。没有中序就无法划分左右。

    重建步骤（前序 + 中序）：

    1. 前序第一个是根
    2. 在中序中找到根，左边是左子树，右边是右子树
    3. 递归处理左右子树

    2.4 Huffman 树¶

    构造：每次取权值最小的两棵树合并，新树权值为两者之和。

    WPL（带权路径长度）： \(\text{WPL} = \sum (\text{叶子的深度} \times \text{叶子的权值})\)

    性质：

    • Huffman 树的 WPL 最小
    • 叶子数 = 原始权值个数
    • 没有度为 1 的结点（严格二叉树）
    • 若叶子数为 \(n\)，总结点数 \(2n-1\)

    例题：权值 \(\{2,3,5,7\}\)，构造 Huffman 树并求 WPL。

    • 合并 2+3=5 → 现在是 \(\{5,5,7\}\)
    • 合并 5+5=10 → \(\{7,10\}\)
    • 合并 7+10=17
    • WPL：2 和 3 深度 3，5(原) 深度 2，7 深度 1 \(= 2\times3 + 3\times3 + 5\times2 + 7\times1 = 6+9+10+7 = 32\)

    2.5 树的重心、直径、LCA¶

    树的重心：删去该点后，剩余连通块中最大块的大小最小的点。

    • 等价刻画：重心 \(u\) 满足所有子树大小 \(\le n/2\)
    • 一棵树最多有 2 个重心，若有 2 个则它们相邻

    树的直径：树中最长的简单路径。

    • 求法：两遍 BFS/DFS —— 从任一点 \(a\) 走到最远点 \(b\)，再从 \(b\) 走到最远点 \(c\)，则 \(b \to c\) 即直径

    LCA（最近公共祖先）：

    • 暴力：两点同时向上跳，\(O(h)\)
    • 倍增：\(O(n\log n)\) 预处理，\(O(\log n)\) 查询
    • fa[u][k] 表示 \(u\) 的第 \(2^k\) 个祖先

    LCA 性质：\(\text{dist}(u,v) = \text{dep}[u] + \text{dep}[v] - 2\,\text{dep}[\text{LCA}(u,v)]\)

    第三部分：数据结构计数（手算模拟必考）¶

    3.1 哈希表 —— 线性探查（5 年 4 考，必考）¶

    线性探查（Linear Probing）规则：

    1. 计算 \(H(key) = key \bmod M\)
    2. 若该位置空 → 放入
    3. 若冲突 → 依次试 \(H+1,\ H+2,\ \ldots\)，到表尾回绕到表头
    4. 直到找到空位

    例题（2025 T6）：表长 13，\(H(key)=key \bmod 13\)，依次插入 \(18, 26, 35, 9, 68, 74\)，问 74 最终在哪个位置？

    关键字 \(key \bmod 13\) 探查过程 最终位置
    18 5 5 空 → 放入 5
    26 0 0 空 → 放入 0
    35 9 9 空 → 放入 9
    9 9 9 占 → 10 空 → 放入 10
    68 3 3 空 → 放入 3
    74 9 9 占 → 10 占 → 11 空 → 放入 11

    答案：11

    其他冲突解决方案：

    方法 类型 探查序列
    线性探查 闭散列 \(H,\ H+1,\ H+2,\ldots\)
    二次探查 闭散列 \(H,\ H+1^2,\ H-1^2,\ H+2^2,\ H-2^2,\ldots\)
    双重散列 闭散列 \(H + i \cdot H_2(key)\)
    链地址法 开散列 同位置挂链表

    装载因子 $\alpha = $ 已存元素数 \(/\) 表长。建议 \(\alpha \le 0.7\)（闭散列）。

    ⚠️ 易错：探查到表尾要回绕到下标 0；另外，闭散列删除元素要打删除标记而非直接清空，否则会截断探查链。

    3.2 堆（优先队列）¶

    性质：

    • 小根堆：父 \(\le\) 子；大根堆：父 \(\ge\) 子
    • 是完全二叉树 → 可用数组存储

    插入（上浮 sift up）：放末尾，与父比较，不满足则交换，直到满足。

    删除堆顶（下沉 sift down）：末尾元素放到堆顶，与较小的子（大根堆取较大的子）比较交换，直到满足。

    复杂度：插入、删除 \(O(\log n)\)；建堆 \(O(n)\)（自底向上）；取最值 \(O(1)\)。

    常考：给一个插入/删除序列，写出最终数组状态。务必逐次模拟，不要跳步。

    3.3 Trie 树（字典树）¶

    结点数计算（2025 T4 考过）：

    \(\boxed{\text{结点数} = (\text{所有字符串的}\textbf{不重复前缀}\text{个数}) + 1\text{（根）}}\)

    例题（2025 T4）：插入 "cat", "car", "cart", "case", "dog", "do"，结点数？

    列出所有前缀并去重：

    • cat → c, ca, cat
    • car → c, ca, car
    • cart → c, ca, car, cart
    • case → c, ca, cas, case
    • dog → d, do, dog
    • do → d, do

    不重复前缀：c, ca, cat, car, cart, cas, case, d, do, dog = 10 个 加根：\(\boxed{11}\)

    复杂度：插入、查询均为 \(O(L)\)，\(L\) 为字符串长度。

    3.4 线段树¶

    结构：满二叉树，根表示 \([1,n]\)，每个结点表示一个区间。

    区间查询访问的结点数（2025 T3 考过）：

    规律：每层最多访问 4 个结点（左右各 2 个"边界"结点），故总数 \(\le 4\lceil\log_2 n\rceil\)。 但实际数量通常远小于上界，需要按递归过程逐层数。

    例题（2025 T3）：\(n=16\)，查 \([3,11]\)，访问结点数？

                        [0,15]           ← 1
                  /        \
             [0,7]          [8,15]   ← 2, 3
            /     \        /      \
        [0,3]    [4,7]  [8,11]  [12,15]
        /   \                         
    [0,1] [2,3]                       
    /  \   /  \                       
  0,1  2,3 4,5 6,7

    递归路径：

    1. [0,15] 部分重叠 → 递归
    2. [0,7] 部分重叠 → 递归
    3. [0,3] 部分重叠 → 递归
    4. [2,3] 部分重叠 → 递归
    5. [3,3] 完全包含 ✓
    6. [4,7] 完全包含 ✓
    7. [8,15] 部分重叠 → 递归
    8. [8,11] 完全包含 ✓

    共 8 个结点 → 答案 8

    复杂度：建树 \(O(n)\)，查询/修改 \(O(\log n)\)，区间修改（带懒标记）\(O(\log n)\)。

    3.5 并查集¶

    操作：find（查根）、union（合并）、路径压缩 + 按秩合并。

    复杂度：路径压缩 + 按秩合并后，单次操作 \(O(\alpha(n))\)（反阿克曼函数， practically 常数）。

    常考：给合并序列，写 fa 数组最终状态；或判断合并后连通块个数。

    3.6 STL 容器复杂度速查¶

    容器 插入 删除 查找 底层
    vector 尾 \(O(1)\) 尾 \(O(1)\) \(O(n)\) 数组

    第四部分：排序算法（4/5 年考）¶

    4.1 全表对照（必背）¶

    排序 平均 最坏 最好 空间 稳定 备注
    冒泡 \(O(n^2)\) \(O(n^2)\) \(O(n)\) \(O(1)\) ✅ 有序时提前退出
    选择 \(O(n^2)\) \(O(n^2)\) \(O(n^2)\) \(O(1)\) ❌ 交换可能跨元素
    插入 \(O(n^2)\) \(O(n^2)\) \(O(n)\) \(O(1)\) ✅ 近乎有序时快
    希尔 \(O(n^{1.3})\) \(O(n^2)\) — \(O(1)\) ❌ 分组插入
    归并 \(O(n\log n)\) \(O(n\log n)\) \(O(n\log n)\) \(O(n)\) ✅ 唯一稳定的 \(O(n\log n)\)
    快速 \(O(n\log n)\) \(O(n^2)\) \(O(n\log n)\) \(O(\log n)\) ❌ 实际最快
    堆 \(O(n\log n)\) \(O(n\log n)\) \(O(n\log n)\) \(O(1)\) ❌ 空间最优
    计数 \(O(n+k)\) \(O(n+k)\) \(O(n+k)\) \(O(n+k)\) ✅ \(k\) 为值域
    基数 \(O(d(n+k))\) 同 同 \(O(n+k)\) ✅ \(d\) 为位数

    稳定性记忆口诀：

    • 稳定：冒泡、插入、归并、计数、基数、桶
    • 不稳定：选择、希尔、快排、堆排

    4.2 稳定性是什么¶

    相等元素在排序后的相对次序保持不变。

    例：[3₁, 1, 3₂]，若排序后是 [1, 3₁, 3₂] → 稳定；若是 [1, 3₂, 3₁] → 不稳定。

    为什么选择排序不稳定：每次从后面选最小的与当前位置交换，跨越交换会打乱相等元素的顺序。 例：[2₁, 2₂, 1] → 第一轮把 1 与 2₁ 交换 → [1, 2₂, 2₁] → 不稳定。

    4.3 快排的三个陷阱（高频）¶

    1. 最坏 \(O(n^2)\)：对已排序数组，若取首元素为 pivot，每次划分极不均匀。
    2. 递归深度：最好 \(O(\log n)\)，最坏 \(O(n)\)。2024 年考过"限制递归深度的快排"。
    3. pivot 选择：随机化 / 三数取中可避免最坏情况。

    快排 partition 的两种写法：

    • Lomuto：单指针，简单
    • Hoare：双指针，交换次数少

    六、易错清单¶

    1. 欧拉图要"连通 + 度数全偶"，两个条件都要检查
    2. 哈密顿回路无简洁判定公式
    3. 前序 + 后序不能唯一确定二叉树（必须有中序）
    4. 完全二叉树深度是 \(\lfloor\log_2 n\rfloor+1\)，不是 \(\lceil\log_2 n\rceil\)
    5. 哈希线性探查到表尾要回绕，且删除要打标记
    6. Trie 结点数 = 不重复前缀 + 1（根）
    7. Dijkstra 不支持负权
    8. 稳定排序包括冒泡、插入、归并；快排、堆排、选择、希尔都不稳定
    9. 栈是后进先出，队列是先进先出（送分题别手滑）
    10. MST 只保证总权最小，不保证任意两点路径最短

    七、自测（答案在最后）¶

    1. 一个连通图有 4 个顶点，度数分别为 3,3,3,3，它是否有欧拉回路？
    2. 一棵二叉树有 15 个结点，其中度为 2 的有 6 个，问叶子有几个？
    3. 表长 11，\(H(key)=key\bmod 11\)，依次插入 12, 23, 34, 45，45 最终在哪个位置？
    4. 插入 "he", "her", "his", "how" 到空 Trie，结点数是多少？
    5. 权值 {1,2,3,4,5} 的 Huffman 树 WPL 是多少？
    答案 1. **没有**。欧拉回路要求「连通**且**所有顶点度数为偶数」，这里 4 个顶点度数全是 3（奇数），不满足。 补充：欧拉路径要求奇度顶点恰为 0 或 2 个，这里有 **4 个**奇度顶点，所以**欧拉路径也不存在**。 （这个图就是 $K_4$，度数之和 $3\times4=12=2m$，故 $m=6$，符合握手定理。） 2. $n_0 = n_2 + 1 = \mathbf{7}$ 3. 12→1；23→1 冲突→2；34→1 冲突→2 冲突→3；45→1,2,3 均占→**4**。答案 **4** 4. 前缀：`h, he, her, hi, his, ho, how` = 7 个，加根 = **8** 5. 合并：1+2=3 → {3,3,4,5}；3+3=6 → {4,5,6}；4+5=9 → {6,9}；6+9=15 WPL = 1×3 + 2×3 + 3×2 + 4×2 + 5×2 = 3+6+6+8+10 = **33**
