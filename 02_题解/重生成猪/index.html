    C. 重生成猪¶

    赛时复盘¶

    这是数位 DP 专题模拟赛的 T3，赛时先写了个暴力的数位DP，然后对于 p == 5 和 p == 25 两个特殊性质，分别推导组合数公式，终于得到 30 分。 数学推导略，相关内容详见

    组合数学与计数原理¶

    这也使我获得本场比赛最高分，这提示要抓住一切能写的部分分，这或许就能拉开差距。 其次，数学非常重要，是信奥的基础。

    赛后发现：这道题的第一步转化非常巧妙：¶

    • 对于任意一个方案，都可以看作若干个形如 00000.....11111 的数相加（前面一段 0，后面一段 1，位数为 N）。
    • 因为加上这样的一个数，就相当于取一个后缀，让这些位都 + 1。
    • 为了保证每个数都在 [1, 9] 内，我们让初始的每一位都是 1，限制最多加 8 次这样的数。

    一、题目大意¶

    求长度为 N 的 N 位整数个数，对 999911659 取模。

    满足：

    • 每一位 a_i 是 1~9 之间的整数
    • 数字非降：a₁ ≤ a₂ ≤ ... ≤ a_N
    • 整个数能被 P 整除

    数据范围：1 ≤ N ≤ 10¹⁸，1 ≤ P ≤ 500

    二、第一个巧妙转化：非降序列 = 多个 θ1 数相加¶

    2.1 θ1 数的定义¶

    θ1 数：形如 000...0111...1 的 N 位数，即前面一段是 0，后面一段是 1。

    例如 N = 5 时，θ1 数有：

    • 00001（第 5 位起都是 1）
    • 00011（第 4 位起都是 1）
    • 00111（第 3 位起都是 1）
    • 01111（第 2 位起都是 1）
    • 11111（第 1 位起都是 1）

    共 N 个不同的 θ1 数。

    2.2 转化定理¶

    任意一个非降序列（每位 1~9），都可以表示为 1 个全 1 数 + 最多 8 个 θ1 数相加。

    解释：

    • 初始每一位都是 1（全 1 数）
    • 每次加上一个 θ1 数，相当于把某个后缀的所有位都 +1
    • 因为非降，所以"数字 ≥ k"的位置一定是一个后缀
    • 加第 k 个 θ1 数，就是让数字从 k 升到 k+1 的那个后缀再加 1
    • 最多加到 9，所以最多加 8 次

    例子：N = 3，数字 123

    • 初始：111
    • 加 θ1 数 011（第 2 位起 +1）→ 122
    • 加 θ1 数 001（第 3 位起 +1）→ 123 ✓

    加了 2 个 θ1 数。

    2.3 转化后的问题¶

    我们有 N 个不同的 θ1 数（对应 N 个后缀起点）。
    从中可重复地选出 0~8 个，加上初始的全 1 数，使得总和 mod P = 0。

    求方案数。

    选 0 个 θ1 数 = 全 1 数
    选 8 个 θ1 数 = 某些位置加到了 9

    三、预处理：θ1 数的余数¶

    3.1 f 数组¶

    设 f_i = i 个 1 连起来的数 mod P。
    即 f_i = 111...1（i 个 1）mod P。

    递推式：

    \[ f_i = (f_{i-1} \times 10 + 1) \bmod P \]

    边界：f₀ = 0, f₁ = 1。

    3.2 θ1 数的余数¶

    一个 θ1 数是从第 s 位开始都是 1，共 N 位。
    它的数值 = 111...1（N-s+1 个 1）= f_{N-s+1}

    所以第 s 个 θ1 数的余数 = f_{N-s+1}。

    3.3 g 数组：按余数分组¶

    设 g_r = 余数为 r 的 θ1 数的个数。

    因为 f_i 的值只有 P 种可能，所以 f 数组一定有循环节。
    利用循环节可以快速计算 g 数组（N 可以到 10¹⁸）。

    具体来说：

    • 计算 f₁, f₂, f₃, ... 直到出现重复（找循环节）
    • 设循环开始前有 pre 个元素，循环节长度为 len
    • 那么 g_r = 前 pre 个中余数为 r 的个数 + 完整循环 × 每个循环内的个数 + 剩余部分

    四、分层 DP：最多选 8 个 θ1 数¶

    4.1 状态定义¶

    dp[i][j][k] = 考虑完前 i 种余数（0~P-1），已经选了 j 个 θ1 数，当前总余数为 k 的方案数。

    • i：枚举到第几种余数（0 ~ P-1）
    • j：选了多少个 θ1 数（0 ~ 8）
    • k：当前总余数 mod P（0 ~ P-1）

    4.2 转移¶

    对于第 i 种余数（余数 = i），有 g_i 个这样的 θ1 数。
    我们可以选 h 个（h = 0, 1, ..., 8-j），都是余数为 i 的。

    选 h 个的方案数：从 g_i 个不同的 θ1 数中可重复地选 h 个，用隔板法：

    \[ C(g_i + h - 1, h) \]

    隔板法：把 h 个相同的球放进 g_i 个盒子（可空）= C(h + g_i - 1, g_i - 1) = C(g_i + h - 1, h)

    转移方程：

    \[ dp_{i, j+h, (k + i \times h) \bmod P} \ += \ C(g_i + h - 1, h) \times dp_{i-1, j, k} \]

    4.3 初始状态¶

    dp[-1][0][f_N] = 1

    dp[-1] 表示还没考虑任何余数的 θ1 数
    j = 0：选了 0 个 θ1 数
    k = f_N：初始全 1 数的余数（N 个 1 连起来 mod P）

    4.4 答案¶

    \[ \text{ans} = \sum_{j=0}^{8} dp_{P-1, j, 0} \]

    （选 0~8 个 θ1 数，总余数为 0 的方案数之和）

    五、复杂度分析¶

    部分 复杂度
    找循环节 O(P)
    DP 枚举 i（余数种类） P
    DP 枚举 j（选了几个） 9
    DP 枚举 k（余数） P
    枚举 h（选几个当前余数的） 9
    总时间 O(P × 9 × P × 9) = O(81 P²)

    P = 500 时：81 × 500² = 81 × 250000 ≈ 2000 万次，飞快！

    空间：可以用滚动数组优化到 O(9 × P) = O(P)。

    六、组合数计算¶

    因为 g_i 可以到 10¹⁸，h 最多是 8，所以：

    \[ C(g_i + h - 1, h) = \frac{(g_i + h - 1) \times (g_i + h - 2) \times \dots \times g_i}{h!} \]

    h ≤ 8，直接计算分子 h 项，乘以 inv(h!) 即可。

    ll C(ll g, int h) {
    if (h == 0) return 1;
    ll res = 1;
    for (int i = 0; i < h; i++) {
        res = res * ((g + h - 1 - i) % MOD) % MOD;
    }
    res = res * inv_fact[h] % MOD;
    return res;
}

    九、总结¶

    核心考点：

    1. 非降序列的 θ1 数分解：非降 = 全 1 数 + 最多 8 个后缀全 1 数

      • 这是这道题最巧妙的地方，把 N 位的问题变成了"选 8 个 θ1 数"的问题 2. 找循环节计算 g 数组：利用 f_i = (f_{i-1}×10+1) mod P 的周期性，O(P) 计算 g 数组

    2. 分层 DP + 隔板法组合数：

      • 按余数分层，每层选 h 个
      • 可重复选的方案数用隔板法 C(g+h-1, h)
      • 总复杂度 O(81 P²)

    第一个转化为什么巧妙：

    • 原本是 N 位的序列问题，N ≤ 10¹⁸ 无法直接 DP
    • 转化后变成"从 N 个 θ1 数中选最多 8 个"的问题
    • 因为最多选 8 个，所以可以按余数分组做 DP
    • 时间复杂度只和 P 有关，和 N 几乎无关（只在算 g 数组时用到循环节）
