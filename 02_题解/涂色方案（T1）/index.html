    题解 涂色方案(T1)¶

    赛时复盘¶

    这是这场比赛的 T1，一看无从下手，一看数据范围，先思考 \(n = 1\) 的特殊性质，手玩小数据轻松推出结论。然后写部分分，过了 \(10^3\) 数据，加上特殊性质，期望得分：80pts; 实际得分：80pts;

    题目简介¶

    给定一张 \(n\times m\) 网格，共有 \(k\) 种颜色，编号 \(1 \sim k\)。

    涂色规则¶

    1. 每种颜色必须使用且仅使用一次，涂色顺序任意；
    2. 单次涂色需要选择一个连续子矩阵进行全覆盖；
    3. 涂色优先级：后涂的颜色会覆盖先涂的颜色。

    问题要求¶

    根据最终的网格状态，求出：一共有多少种颜色，有可能是第一个被涂色的颜色。

    核心思想¶

    1. 最小包围矩形¶

    对于任意一种颜色 \(c\)，把网格中所有值为 \(c\) 的格子圈出来，能完整包裹这些格子的最小矩形，称为该颜色的最小包围矩形。

    结合涂色规则可以推出： 想要把所有 \(c\) 颜色的格子都涂上色，涂色时选择的矩阵一定包含这个最小包围矩形。

    结论：颜色 \(c\) 涂色的瞬间，其最小包围矩形内的所有格子，都会被临时染成颜色 \(c\)。

    2. 颜色先后关系推导¶

    假设： 1. 格子最终颜色为 \(x\)； 2. 该格子落在另一种颜色 \(y\) 的最小包围矩形内部。

    逻辑链： - \(y\) 涂色时，该格子被覆盖为 \(y\)； - 最终格子变回 \(x\)，说明 \(x\) 是在 \(y\) 之后涂色； - 因此：\(y\) 先涂，\(x\) 后涂。

    核心结论：被其他颜色最小矩形覆盖的颜色，一定不能作为第一个涂色的颜色。

    3. 特殊特判¶

    题目强制要求：\(k\) 种颜色全部必须使用。 当同时满足以下两个条件： - \(k > 1\)（总颜色数大于 1） - 整张网格只出现了一种颜色

    该颜色的涂色流程必然为：先涂色 → 被其余所有颜色覆盖 → 最后再次涂色。 因此：该颜色绝对无法作为第一个涂色的颜色，需要手动标记排除。

    前置知识：二维差分 + 二维前缀和¶

    在本题中，我们需要对多个矩形区域统一做 \(+1\) 操作，如果暴力遍历每个矩形内所有格子修改，复杂度会达到 \(O(k\cdot nm)\)，大数据场景极易超时。 而 二维差分 可以把「矩形区间修改」优化到 \((O(1))\)，再通过二维前缀和还原出原数组，是二维区间操作的经典算法。

    一、一维差分回顾（铺垫）¶

    先回忆一维差分，方便理解二维逻辑。 对于一维数组，想要对区间 \(([L,R])\) 全体 \((+1)\)： 

    diff[L] += 1
diff[R(+1)] -= 1
    最后对差分数组求一维前缀和，就能得到原数组修改后的结果。

    二维差分是一维差分在矩阵上的拓展，核心思想一致：只在区间边界打标记，不修改区间内部。

    二、二维差分原理与公式¶

    1. 适用场景¶

    给定二维矩阵，对任意子矩形 \([r_1,c_1] \sim [r_2,c_2]\)（左上角、右下角坐标）执行区间整体加 1。

    2. 标准公式¶

    设原矩阵为 \(a\)，差分数组为 \(diff\)，执行如下 4 条语句即可完成一次矩形加 1： 

    diff[r1][c1]     += 1;
diff[r1][c2 + 1] -= 1;
diff[r2 + 1][c1] -= 1;
diff[r2 + 1][c2 + 1] += 1;

    3. 逐句原理拆解（核心）¶

    我们把整个矩阵看成平面坐标系，矩形修改的本质是控制增量的生效范围： 1. diff[r1][c1] += 1 从位置 \((r_1,c_1)\) 开始，全局增量 \(+1\)，整个右下方区域都会受到这个增量影响。 2. diff[r1][c2(+1)] -= 1 在同一行、矩形右侧外一列位置，抵消增量。作用：限定增量只在矩形列范围内生效。 3. diff[r2(+1)][c1] -= 1 在同一列、矩形下侧外一行位置，抵消增量。作用：限定增量只在矩形行范围内生效。 4. diff[r2(+1)][c2(+1)] += 1 右下角对角点位置补 \(+1\)。 原因：上面两步做了两次 -1，该位置被重复抵消，需要修正误差，保证边界计算正确。

    一句话总结：四个点组合，精准框出矩形范围，让增量只作用在目标矩形内部。

    四、二维前缀和（还原数组）¶

    1. 作用¶

    差分数组只保存了修改标记，无法直接使用。 通过二维前缀和，可以把差分标记还原为每个格子的真实数值。

    2. 执行顺序¶

    1. 遍历每一行，对每行做一维前缀和；
    2. 遍历每一列，对每一列做一维前缀和。

    3. 结果含义（结合本题）¶

    在本题中： - 我们对每一个颜色的最小包围矩形都执行一次差分 \((+1)\)； - 前缀和完成后，\((cov[i][j])\) 表示：格子 \(((i,j))\) 一共被多少个颜色的包围矩形覆盖。

    五、结合本题的使用逻辑¶

    1. 遍历所有颜色，取出该颜色的最小包围矩形 \((r_1,c_1) \sim (r_2,c_2)\)；
    2. 对该矩形执行二维差分四步操作，区间 \((+1)\)；
    3. 全部颜色处理完毕后，执行二维前缀和，得到每个格子的总覆盖次数；
    4. 判定规则： 每个格子一定会被自身颜色的矩形覆盖 1 次，因此： $$ (cov[i][j]) - 1 > 0 $$ 代表该格子还被其他颜色的矩形覆盖过 \(\implies\) 当前颜色必然后涂，不能作为第一个。

    AC code¶

    #include <bits/stdc++.h>
using namespace std;

int n, m, k;

// 每种颜色的最小/最大行、列
vector<int> line_mi, line_ma;
vector<int> row_mi, row_ma;

// 网格矩阵
vector<vector<int>> mp;
// vis: 颜色是否在网格中出现  check: 颜色是否不能作为第一个
vector<bool> check, vis;

// 二维差分数组、覆盖次数统计数组
vector<vector<int>> dif2, cov2;

int main() {
    freopen("paint.in", "r", stdin);
    freopen("paint.out", "w", stdout);
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> n >> m >> k;

    // 动态分配空间，下标从 1 开始使用
    mp.resize(n + 1, vector<int>(m + 1));
    vis.resize(k + 1, false);
    check.resize(k + 1, false);

    // 边界初始化：最小行列设极大值，最大行列设0
    line_mi.resize(k + 1, 0x3f3f3f3f);
    line_ma.resize(k + 1, 0);
    row_mi.resize(k + 1, 0x3f3f3f3f);
    row_ma.resize(k + 1, 0);

    // 读入网格 + 计算每种颜色的最小包围矩形
    for (int i = 1; i <= n; i ++) {
        for (int j = 1; j <= m; j ++) {
            cin >> mp[i][j];
            int c = mp[i][j];
            vis[c] = true;
            line_mi[c] = min(line_mi[c], i);
            line_ma[c] = max(line_ma[c], i);
            row_mi[c] = min(row_mi[c], j);
            row_ma[c] = max(row_ma[c], j);
        }
    }

    // 多开2行2列，防止 r2\(+1\) / c2\(+1\) 数组越界
    dif2.resize(n + 2, vector<int>(m + 2, 0));
    cov2.resize(n + 2, vector<int>(m + 2, 0));

    // 二维差分：对每个颜色的矩形区间 \(+1\)
    for (int id = 1; id <= k; id ++) {
        if (!vis[id]) continue;
        int r1 = line_mi[id], r2 = line_ma[id];
        int c1 = row_mi[id], c2 = row_ma[id];
        dif2[r1][c1]++;
        dif2[r1][c2 + 1]--;
        dif2[r2 + 1][c1]--;
        dif2[r2 + 1][c2 + 1]++;
    }

    // 第一步：逐行求前缀和
    for (int i = 1; i <= n; i++) {
        int sum = 0;
        for (int j = 1; j <= m; j++) {
            sum += dif2[i][j];
            cov2[i][j] = sum;
        }
    }
    // 第二步：逐列求前缀和
    for (int j = 1; j <= m; j++) {
        int sum = 0;
        for (int i = 1; i <= n; i++) {
            sum += cov2[i][j];
            cov2[i][j] = sum;
        }
    }

    // 标记无法作为第一个的颜色
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            int now_c = mp[i][j];
            // 减去自身覆盖，剩余>0 说明被其他颜色覆盖
            if (cov2[i][j] - 1 > 0) {
                check[now_c] = true;
            }
        }
    }

    // 特判：\(k > 1\) 且整张网格只出现一种颜色
    int appear = 0;
    int only_col = 0;
    for (int i = 1; i <= k; ++i) {
        if (vis[i]) {
            appear++;
            only_col = i;
        }
    }
    if (k > 1 && appear == 1) {
        check[only_col] = true;
    }

    // 统计答案：总颜色数 - 非法颜色数
    int ans = 0;
    for (int i = 1; i <= k; i ++) {
        if(check[i]) ans ++;
    }
    cout << k - ans << '\n';

    return 0;
}

    复杂度分析¶

    1. 遍历网格、求解最小包围矩形：\((O(nm))\)
    2. 遍历颜色、执行二维差分：\((O(k))\)
    3. 二维前缀和还原覆盖次数：\((O(nm))\)
    4. 标记、特判、统计答案：\(O(nm + k)\)

    总时间复杂度：\(\boldsymbol{O(nm + k)}\)¶

    易错点¶

    1. 必须执行 cov - 1 每个格子必然被自身颜色的矩形覆盖 1 次，必须减去自身贡献，才能判断是否被其他颜色覆盖。

    2. 不要遗漏单色特判 \((k > 1)\) 但网格仅出现一种颜色时，该颜色一定无法作为首位，是本题经典坑点。

    解题总结¶

    1. 核心逻辑：利用最小包围矩形确定每种颜色的覆盖范围，结合涂色覆盖规则推导颜色先后关系；
    2. 算法优化：使用二维差分替代暴力枚举矩形，将矩形修改从 \((O(nm))\) 降为 \((O(1))\)，是本题核心考点；
    3. 注意题目特殊规则的特判，覆盖所有边界场景；
