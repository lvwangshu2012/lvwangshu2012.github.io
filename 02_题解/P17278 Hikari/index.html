    P17278 Hikari¶

    复盘¶

    本题的核心在于 数学： - 通过平方裂项法将问题转化为可闭式计算的形式。 - 推导完成后，代码实现仍有不少边界细节需要仔细处理。

    一、题意¶

    题目¶

    构造长度为 \(n+1\) 的序列 \(x_0, x_1, \dots, x_n\)，满足：

    1. \(x_0 = 0\)
    2. 对任意 \(1 \le i \le n\)，\(|x_i| = |x_{i-1} + 1|\)
    3. \(m\) 条限制：\(x_{w_i} = c_i\)

    求不和谐值 \(s(x) = \left|\sum\limits_{i=0}^n x_i\right|\) 的最小值。无解输出 \(-1\)。

    理解¶

    第 \(i\) 步的转移：\(x_{i-1}\) 先加 1，然后可以选择取正或取负。

    换句话说，每一步有两种选择：

    • 不取反：\(x_i = x_{i-1} + 1\)（沿原方向继续）
    • 取反：\(x_i = -(x_{i-1} + 1)\)（翻转符号）

    我们的目标是让最终序列的总和的绝对值尽可能小。

    二、核心性质一：区间和是定值¶

    这是本题最关键的观察。

    平方裂项法¶

    给定 \(x_a = A\)，\(x_b = B\)，距离 \(D = b - a\)。我们想知道 \(\sum\limits_{i=a+1}^{b} x_i\) 的值。

    对递推式两边平方：

    \[ x_i^2 = (x_{i-1} + 1)^2 \]

    展开右边：

    \[ x_i^2 = x_{i-1}^2 + 2x_{i-1} + 1 \]

    移项，把平方项放左边：

    \[ x_i^2 - x_{i-1}^2 = 2x_{i-1} + 1 \]

    这个式子对每一步都成立。现在对 \(i = a+1, a+2, \dots, b\) 求和：

    \[ \sum_{i=a+1}^{b} (x_i^2 - x_{i-1}^2) = \sum_{i=a+1}^{b} (2x_{i-1} + 1) \]

    左边是裂项相消：

    \[ x_b^2 - x_a^2 = B^2 - A^2 \]

    右边拆成两部分：

    \[ 2\sum_{i=a+1}^{b} x_{i-1} + \sum_{i=a+1}^{b} 1 = 2\sum_{j=a}^{b-1} x_j + D \]

    （令 \(j = i-1\)，当 \(i = a+1\) 时 \(j = a\)；当 \(i = b\) 时 \(j = b-1\)）

    左右相等：

    \[ B^2 - A^2 = 2\sum_{j=a}^{b-1} x_j + D \]

    整理出我们想要的和：

    \[ \sum_{j=a}^{b-1} x_j = \frac{B^2 - A^2 - D}{2} \]

    调整下标¶

    我们想要的是从 \(a+1\) 到 \(b\) 的和（即走完整个区间后的和），而上面得到的是从 \(a\) 到 \(b-1\) 的和。

    差了一个 \(x_b\)，多了一个 \(x_a\)：

    \[ \sum_{i=a+1}^{b} x_i = \sum_{i=a}^{b-1} x_i + x_b - x_a \]

    代入：

    \[ \sum_{i=a+1}^{b} x_i = \frac{B^2 - A^2 - D}{2} + B - A \]

    结论¶

    相邻两个限制点之间的和是一个定值，只由端点值 \(A, B\) 和距离 \(D\) 决定，与中间怎么走无关！

    推论¶

    整个序列的总和 \(\sum\limits_{i=0}^n x_i\) 完全由 \(x_n\) 的值决定。中间的 \(m\) 条限制只起到判断可行性的作用，它们不影响总和的计算方式。

    三、核心性质二：可达性判定¶

    知道了区间和是定值，接下来需要解决：从 \(A = x_a\) 出发，走 \(D\) 步，能不能到达 \(B = x_{a+D}\)？

    枚举找规律¶

    记 \(S_D(A)\) 为从 \(A\) 出发走 \(D\) 步后可能的取值集合。

    • \(D = 0\)：\(S_0(A) = \{A\}\)
    • \(D = 1\)：\(x_1 = \pm(A+1)\)，故 \(S_1(A) = \{A+1,\ -A-1\}\)
    • \(D = 2\)：从 \(A+1\) 走一步得 \(\{A+2, -A-2\}\)；从 \(-A-1\) 走一步得 \(\{-A, A\}\)。合并：\(S_2(A) = \{A+2,\ A,\ -A,\ -A-2\}\)
    • \(D = 3\)：类似地，\(S_3(A) = \{A+3,\ A+1,\ A-1,\ -A+1,\ -A-1,\ -A-3\}\)

    规律总结¶

    \(S_D(A)\) 由两部分组成：

    • 正向链：\(A+D,\ A+D-2,\ A+D-4,\ \dots\)，一直到 \(A-D+2\)
    • 反向链：\(-A+D-2,\ -A+D-4,\ \dots\)，一直到 \(-A-D\)

    为什么正向链的最后一项是 \(A-D+2\) 而不是 \(A-D\)？

    因为每一步"取正"的时候值是连续变化的，但第一次"取反"会产生跳变。当你还没来得及取反到跨越 0 的时候，中间会有一段缺口。

    直观理解¶

    想象你从 \(A\) 出发，每一步加 1 然后可以翻转。

    • 如果你一直不取反，你就沿着正方向一直走：\(A+1, A+2, \dots, A+D\)
    • 如果你在第 \(k\) 步取反一次，你就从 \(A+k\) 跳到 \(-(A+k)\)，然后继续走
    • 取反两次相当于没取反（但路径不同）... 实际上取反两次后你回到类似的轨迹

    关键是：当步数 \(D\) 不够大时（\(D \le A\)），你还没走到 0 以下，因此 0 附近有一段"盲区"是达不到的。只有当 \(D > A\) 时，你才能下探到 0 附近，盲区消失。

    判定条件¶

    综合起来，\(B\) 从 \(A\) 出发 \(D\) 步可达，当且仅当：

    1. 绝对值上界：\(|B| \le A + D\)
      • 一直往上走最多到 \(A+D\)，一直往上走然后翻转到最下面是 \(-(A+D)\)
    2. 奇偶性匹配：\(B \equiv A + D \pmod{2}\)
      • 每一步绝对值加 1（当 \(x_{i-1} \ge 0\) 时）或减 1（当 \(x_{i-1} < 0\) 时），但最终 \(|B|\) 与 \(A+D\) 的奇偶性相同
      • 等价表述：\(B - A - D\) 是偶数
    3. 盲区约束：若 \(A - D + 2 > 0\)（即 \(D < A + 2\)，步数不够多），则 \(|B| \ge A - D + 2\)
      • 中间靠近 0 的地方达不到，绝对值不能太小

    为什么条件 3 是 \(A - D + 2\)？¶

    正向链的最小元素是 \(A - D + 2\)（从 \(A+D\) 每次减 2，走 \(D-1\) 次：\(A+D - 2(D-1) = A - D + 2\)）。

    反向链的最大元素（最接近 0 的）是 \(-A + D - 2\)，其绝对值也是 \(A - D + 2\)。

    所以两边都到不了绝对值小于 \(A - D + 2\) 的数。

    当 \(A - D + 2 \le 0\) 时，两条链在 0 附近"接上了"，没有盲区。

    四、算法设计¶

    整体思路¶

    1. 加虚拟限制 \((0, 0)\)（因为 \(x_0 = 0\)）
    2. 排序 + 去重 + 检查冲突
    3. 依次检查相邻限制的可达性，任意一对不可达则无解
    4. 计算前缀和（利用区间和公式）
    5. 在最后一段找最优的 \(y = x_n\)，使得 \(|\text{总和}|\) 最小

    最后一段的优化¶

    设最后一个限制点的值为 \(C\)，还剩 \(D\) 步，\(y = x_n\)。

    总和的两倍为：

    \[ 2 \cdot \text{sum} = y^2 + 2y + 2K \]

    其中 \(2K = 2 \cdot \text{prefix} - C^2 - D - 2C\) 是常数。

    推导：
    \(\text{sum} = \text{prefix} + \frac{y^2 - C^2 - D}{2} + y - C\)
    \(2 \cdot \text{sum} = 2 \cdot \text{prefix} + y^2 - C^2 - D + 2y - 2C = y^2 + 2y + (2 \cdot \text{prefix} - C^2 - D - 2C)\)

    我们的目标是最小化 \(|\text{sum}| = |y^2 + 2y + 2K| / 2\)。

    令 \(g(y) = y^2 + 2y + 2K = (y+1)^2 + (2K - 1)\)。

    这是一个开口向上的抛物线，对称轴为 \(y = -1\)。

    分情况讨论¶

    情况一：\(2K \ge 1\)（抛物线恒正）

    此时 \(g(y) \ge 2K - 1 \ge 0\) 恒成立，\(|g(y)| = g(y)\)。

    最小值在顶点 \(y = -1\) 处取得，值为 \(2K - 1\)。

    我们需要在可达值中找离 \(y = -1\) 最近的。

    情况二：\(2K < 1\)（抛物线穿过 x 轴）

    此时 \(g(y) = 0\) 有两个实根：

    \[ y = -1 \pm \sqrt{1 - 2K} \]

    \(|g(y)|\) 的最小值为 0（在根处取得）。如果根是可达的，答案就是 0；否则找离根最近的可达值。

    候选点策略¶

    可达值集合是分段的等差数列，直接枚举所有值不现实（\(D\) 可达 \(10^9\)）。

    但由于目标函数是凸的（先减后增），最小值一定出现在离目标点（根或顶点）最近的几个位置。我们只需要枚举少量候选点：

    1. 上下界：\(A+D\) 和 \(-(A+D)\)
    2. 盲区边界：如果有盲区，盲区的上下边缘（即 \(A-D+2\) 和 \(-(A-D+2)\)）
    3. 根附近：两个根的周围各几个点
    4. 顶点附近：\(y = -1\) 的周围几个点

    总共也就十几个候选点，逐一判断可达性并计算函数值，取最小即可。

    五、AC code¶

    #include <bits/stdc++.h>
using namespace std;

using ll = long long;

bool check(ll A, ll D, ll B) {
    ll max_abs, min_abs;
    if (A >= 0) {
        max_abs = A + D;
        if (D <= A + 1)
            min_abs = A - D + 2;
        else
            min_abs = (D - A) & 1;
    } else {
        ll a = -A;
        max_abs = a + D - 2;
        if (D <= a)
            min_abs = a - D;
        else
            min_abs = (D - a) & 1;
    }
    if (llabs(B) > max_abs) return false;
    if (llabs(B) < min_abs) return false;
    if ((B & 1) != (max_abs & 1)) return false;
    return true;
}

ll cacl(ll A, ll B, ll D) {
    return (B * B - A * A - D) / 2 + B - A;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T; cin >> T;
    while (T --) {
        ll n; int m;
        cin >> n >> m;

        vector<pair<ll, ll>> lims;
        lims.emplace_back(0, 0);
        for (int i = 1; i <= m; i++) {
            ll w, c;
            cin >> w >> c;
            lims.emplace_back(w, c);
        }

        sort(lims.begin(), lims.end());

        bool flag = true;
        vector<pair<ll, ll>> vec;
        for (auto& p : lims) {
            if (!vec.empty() && p.first == vec.back().first) {
                if (p.second != vec.back().second)
                    flag = false;
            } else {
                vec.push_back(p);
            }
        }
        if (!flag) {
            cout << -1 << '\n';
            continue;
        }

        ll pre = 0;
        for (int i = 1; i < (int)vec.size(); i++) {
            ll w1 = vec[i - 1].first, c1 = vec[i - 1].second;
            ll w2 = vec[i].first, c2 = vec[i].second;
            ll D = w2 - w1;
            if (!check(c1, D, c2)) {
                flag = false;
                break;
            }
            pre += cacl(c1, c2, D);
        }
        if (!flag) {
            cout << -1 << '\n';
            continue;
        }

        ll lst_c = vec.back().second;
        ll D = n - vec.back().first;

        if (D == 0) {
            cout << llabs(pre) << '\n';
            continue;
        }

        ll twoK = 2 * pre - lst_c * lst_c - D - 2 * lst_c;

        ll max_abs, min_abs;
        if (lst_c >= 0) {
            max_abs = lst_c + D;
            if (D <= lst_c + 1)
                min_abs = lst_c - D + 2;
            else
                min_abs = (D - lst_c) & 1;
        } else {
            ll a = -lst_c;
            max_abs = a + D - 2;
            if (D <= a)
                min_abs = a - D;
            else
                min_abs = (D - a) & 1;
        }

        ll upper = max_abs;
        ll lower = -max_abs;
        bool has_gap = (min_abs > 0);
        ll gap_low = min_abs;

        vector<ll> cand;
        cand.push_back(upper);
        cand.push_back(lower);

        if (has_gap) {
            ll fp = gap_low;
            if (((fp ^ upper) & 1)) fp++;
            if (fp <= upper) cand.push_back(fp);
            ll ln = -gap_low;
            if (((ln ^ upper) & 1)) ln--;
            if (ln >= lower) cand.push_back(ln);
        }

        ll disc = 1 - twoK;
        if (disc >= 0) {
            ll s = sqrt(disc);
            while (s * s > disc) s--;
            while ((s + 1) * (s + 1) <= disc) s++;
            for (int d = -2; d <= 2; d++) {
                cand.push_back(-1 + s + d);
                cand.push_back(-1 - s + d);
            }
        } else {
            for (int d = -2; d <= 2; d++)
                cand.push_back(-1 + d);
        }

        ll ans = LLONG_MAX;
        for (ll y : cand) {
            if (y < lower || y > upper) continue;
            if (((y ^ upper) & 1)) continue;
            if (has_gap && llabs(y) < gap_low) continue;
            ll val = llabs(y * y + 2 * y + twoK);
            ans = min(ans, val);
        }

        cout << ans / 2 << '\n';
    }

    return 0;
}
