    停车场¶

    题目描述¶

    一个矩形停车场由 \(n \times m\) 个边长为 1 的正方形停车位组成。其中：

    • . 表示该位置没有停车（空位）；
    • # 表示该位置已经停了车（占用）。

    题目保证：所有变化都只会有车进入停车场，即只可能发生「. 变成 #」这种单向修改，永远不会出现「# 变成 .」。

    共有 \(k\) 辆车先后进入停车场。请在每辆车进入之后，输出当时整个停车场内能容纳的最大空正方形的边长。

    题意抽象¶

    给一张 \(n \times m\) 的 0/1 网格（0 = 空，1 = 车），初始有若干个 1。之后依次执行 \(k\) 次「将某个 0 改为 1」的操作。

    每次操作后，输出网格中所有由 0 构成的正方形中，边长最大的那一个。

    思路核心¶

    1. 倒序处理（时光倒流）：把「加车」换成「撤车」¶

    正向时间轴上，每一步都是「某个空格变车」。如果直接在线处理，需要在每一次操作后重新计算整张图的最大空正方形，代价很高。

    把时间轴反过来：先把所有车（包括初始车和 \(k\) 个进入位置）都放上，再依次把第 \(k, k-1, \dots, 1\) 辆车「撤走」（# 变回 .）。

    倒序有两个关键性质：

    1. 空位只增不减：每一步都是新增空位，因此最大空正方形边长只可能变大。
    2. 新增答案的来源很集中：在第 \(i\) 步把 \((x_i, y_i)\) 撤走以后，「相比上一步新出现的空正方形」必然包含 \((x_i, y_i)\)，从而必然跨过第 \(x_i\) 行。换句话说，每一步只会影响「跨过第 \(x_i\) 行的最大空正方形」，其它行上的最大正方形边长在这一步不会变。

    利用这两点，只需维护一个全局 cur_best，每一步把「跨第 \(x_i\) 行的最大空正方形」与它取 max 即可；输出时再把这个数组逆序回来。

    2. 用 up[] / down[] 把「行的可行性」压缩成一维¶

    对于每行 \(x\)，我们想快速回答：以 \(x\) 为「穿过行」的条件下，\(m\) 列中最长的空正方形边长是多少。

    为此对每个格子 \((i, j)\) 维护两个值：

    记号 含义
    up[i][j] 从第 \(i\) 行沿第 \(j\) 列向上延伸，连续空位的总长度（含 \((i, j)\) 自身）
    down[i][j] 从第 \(i\) 行沿第 \(j\) 列向下延伸，连续空位的总长度（含 \((i, j)\) 自身）

    当 \((i, j)\) 是车时，up[i][j] = down[i][j] = 0；否则按相邻格子递推即可。

    加入一个空位 \((x, y)\)（在反向意义下是「撤车」）后，只有第 \(y\) 列发生变化，其它列的 up[]、down[] 不受影响。因此该列上 \(n\) 行的 up[*][y]、down[*][y] 都可以在 \(O(n)\) 时间内重新计算。

    3. 跨过第 \(x\) 行的最大空正方形¶

    固定行 \(x\)。把每个列 \(j\) 上的「垂直可用长度」记为

    \[ v[j] = \texttt{up}[x][j] + \texttt{down}[x][j] \]

    （如果空正方形跨过第 \(x\) 行，则 \(v[j]\) 至少要为正方形边长 \(L\) 留出足够纵向覆盖；当 \(\texttt{up}[x][j]\)、\(\texttt{down}[x][j]\) 都按「包含 \((x, j)\)」的语义计算时，可行条件为 \(v[j] \ge L + 1\)；出于对称性，下面的描述都基于这一等价条件。）

    判定：给一个列区间 \([j, i]\)，令 \(L = i - j + 1\)。该区间能形成跨第 \(x\) 行、边长为 \(L\) 的空正方形，当且仅当

    \[ \min_{k \in [j, i]} v[k] \;\ge\; L + 1 \]

    也就是说，要找一个最长的窗口 \([j, i]\)，使窗口内 \(v\) 的最小值不小于窗口长度加一。

    4. 用「双指针 + 单调队列」线性求出最长窗口¶

    维护两个指针 \(j, i\) 和一个单调递增的索引队列 dq，使得 dq.front() 始终是当前窗口 \([j, i]\) 中 \(v\) 值最小者的下标。

    推进 \(i\) 一格：

    1. 把 \(i\) 入队（弹出队尾所有 \(v \ge v[i]\) 的下标，再 push_back(i)），\(O(1)\) 均摊；
    2. 若条件 \(\min v \ge (i - j + 1) + 1\) 不满足，则不断右移 \(j\)，并同步把队首过期的下标弹出；
    3. 记录 best = max(best, i - j + 1)。

    整个过程 \(i\)、\(j\) 各扫一遍，共 \(O(m)\)。

    注：另一种等价的写法是用两个单调队列分别维护「左闭右开滑动窗口的最小 \(v\)」和「右闭左开滑动窗口的最小 \(v\)」，并用「最小的 \(v\) 减去长度不小于 1」作为不变量。本质相同，按团队习惯选用即可。

    5. 整合¶

    把第 1、2、3、4 节拼起来：

    1. 把所有车都标在网格上，预处理 \(O(nm)\) 的 up[][]、down[][]，再遍历所有行跑一次上面的「跨行最大空正方形」过程，求出初始 cur_best；
    2. 倒序处理第 \(k, k-1, \dots, 1\) 步：每一步把 \((x_i, y_i)\) 改成空，\(O(n)\) 重算第 \(y_i\) 列的 up[]、down[]，\(O(m)\) 算跨第 \(x_i\) 行的最大空正方形并与 cur_best 取 max；
    3. 把记录下来的 ans[] 逆序输出。

    时间 / 空间复杂度¶

    维度 量
    时间 \(O(nm + k(n + m))\)
    空间 \(O(nm)\)，主要开销是 up[][]、down[][] 两张 \(n \times m\) 表

    当 \(n, m, k\) 同阶（\(\le 2000\)）时，时间约为 \(O(n^2)\)，实际约 \(1.2 \times 10^7\) 次基本操作，2 s 测速可过；空间 \(2 \times 2000^2 \times 4\,\text{B} = 32\,\text{MB}\)，远小于 512 MB 上限。

    AC code¶

    #include <bits/stdc++.h>
using namespace std;

const int N = 2005;

int n, m, k;
int a[N][N];          // 0 = 空位(.), 1 = 有车(#)
int up[N][N];         // 向上连续空位长度（含自身）
int dn[N][N];         // 向下连续空位长度（含自身）
int res[N];           // res[i] = 第 i 辆车进入后的最大空正方形边长

// 在第 y 列重新计算 up[*][y] 与 dn[*][y]（O(n)）
void rebuild_col(int y) {
    for (int i = 1; i <= n; i++) {
        if (a[i][y] == 0)
            up[i][y] = (i == 1 || a[i - 1][y] == 1) ? 1 : up[i - 1][y] + 1;
        else
            up[i][y] = 0;
    }
    for (int i = n; i >= 1; i--) {
        if (a[i][y] == 0)
            dn[i][y] = (i == n || a[i + 1][y] == 1) ? 1 : dn[i + 1][y] + 1;
        else
            dn[i][y] = 0;
    }
}

// 求「跨过第 x 行」的最大空正方形边长（O(m)）
int max_square_cross_row(int x) {
    int best = 0;
    deque<int> dqU, dqD;      // 分别维护窗口内 up / dn 的最小值
    int L = 1;

    for (int R = 1; R <= m; R++) {
        while (!dqU.empty() && up[x][dqU.back()] >= up[x][R]) dqU.pop_back();
        dqU.push_back(R);
        while (!dqD.empty() && dn[x][dqD.back()] >= dn[x][R]) dqD.pop_back();
        dqD.push_back(R);

        // 窗口 [L, R] 合法当且仅当 窗口内 min(up) + min(dn) >= 窗口长度 + 1
        // （等价于各列的竖直覆盖区间求交，交集长度 >= 边长）
        while (!dqU.empty() && !dqD.empty() &&
                up[x][dqU.front()] + dn[x][dqD.front()] < (R - L + 1) + 1) {
            if (dqU.front() == L) dqU.pop_front();
            if (dqD.front() == L) dqD.pop_front();
            L++;
        }
        best = max(best, R - L + 1);
    }
    return best;
}

int main() {
//  freopen("parking.in",  "r", stdin);
//  freopen("parking.out", "w", stdout);
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> n >> m >> k;
    vector<string> grid(n + 1);
    for (int i = 1; i <= n; i++) {
        cin >> grid[i];
        for (int j = 1; j <= m; j++)
            a[i][j] = (grid[i][j - 1] == '#') ? 1 : 0;
    }

    vector<pair<int, int>> car(k + 1);
    for (int i = 1; i <= k; i++) {
        cin >> car[i].first >> car[i].second;
        a[car[i].first][car[i].second] = 1;   // 把即将进入的车全部先标上
    }

    // 预处理 up / dn
    for (int j = 1; j <= m; j++) rebuild_col(j);

    // 初始答案：停满 k 辆车后的最大空正方形
    int cur_best = 0;
    for (int x = 1; x <= n; x++)
        cur_best = max(cur_best, max_square_cross_row(x));
    res[k] = cur_best;

    // 倒序：依次撤走第 k, k-1, ..., 1 辆车
    // 撤走第 idx 辆车后 => 正向「停了 idx-1 辆车」的状态 => 记入 res[idx-1]
    for (int idx = k; idx >= 1; idx--) {
        int x = car[idx].first, y = car[idx].second;
        a[x][y] = 0;            // 撤车：# 改回 .
        rebuild_col(y);         // 仅重算第 y 列
        cur_best = max(cur_best, max_square_cross_row(x));
        res[idx - 1] = cur_best;
    }

    // 输出正向第 1..k 辆车进入后的答案
    for (int i = 1; i <= k; i++)
        cout << res[i] << '\n';

    return 0;
}

    复盘¶

    • 这道题在「数据范围紧、答案结构单调」的设定下，几乎所有复杂度上的节省都来自「倒序处理」这一步：把单向的「加车」转换成可单调推进的「撤车」，从而避免每次都从头重算答案。
    • 在倒序的单调性之上，把「行级判定」压缩成一维数组 v[]，再把「最长合法窗口」交给双指针 + 单调队列，是子数组类问题的标准技巧；写过一次之后，对所有「找最长满足 \(\min \ge L\) 或 \(\max \le L\) 的子数组」的问题都能复用。
    • 算法层面复杂度 \(O(nm + k(n + m))\) 已经足够，但实际写代码时最容易写错的是「up[] / dn[] 的边界条件」——尤其是处理首行 / 末行、相邻是车这两种 case。
    • 这类「动态修改 + 实时询问最大子结构」的题目，「倒序 + 单调性 + 行级结构」是一个高频考点。在所有类似「只能加、不能减 / 只能减、不能加」的题中都可以优先尝试倒序。（时光倒流）
