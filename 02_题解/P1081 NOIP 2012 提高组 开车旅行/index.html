    P1081 [NOIP 2012 提高组] 开车旅行¶

    题目简述¶

    小 A 和小 B 轮流开车，从某个城市出发一直向东行驶。小 A 总是选择第二近的城市，小 B 总是选择最近的城市（距离相同取海拔低的更近）。每次给定起点 \(s\) 和路程上限 \(x\)，要求计算小 A 和小 B 分别行驶的总距离。此外还需要回答一个最优起点的问题：对于给定的 \(x_0\)，从哪个城市出发，小 A 与小 B 行驶距离之比最小（比值无穷大时取海拔最高者）。

    数据范围：\(n,m \le 10^5\)，海拔互不相同。

    直接模拟每一步会超时，需要高效算法。

    核心思路¶

    整体分两步：

    1. 预处理每个城市的“最近”和“第二近”城市
      因为只能向东行驶，我们可以从右往左扫描城市，用 set 维护已经扫描过的城市（即编号更大的城市），对每个城市只需在海拔附近找最多 4 个候选城市，即可确定最近和次近城市以及对应距离。

    2. 倍增优化模拟
      把“小 A 走一步 + 小 B 走一步”看作一轮。预处理每个城市走 \(2^j\) 轮后到达的城市，以及这一过程中小 A、小 B 各自的总路程。查询时用倍增快速跳过大量轮次，再处理剩余不足一轮的情况。

    下面依次讲解这两部分的细节。

    预处理：快速确定最近和次近城市¶

    为什么要倒序扫描？¶

    题目规定只能向东行驶，即从城市 \(i\) 出发只能去往编号大于 \(i\) 的城市。如果我们从右往左（即 \(n\) 到 \(1\)）遍历城市，当处理到城市 \(i\) 时，所有编号大于 \(i\) 的城市都已经处理完毕，因此可以在一个数据结构中快速查询这些城市的海拔信息，从中找出距离最近和次近的城市。

    用 set 维护候选城市¶

    用一个 set<pair<ll,int>> 存储已经扫描过的城市，其中第一维是海拔，第二维是城市编号。set 内部按海拔升序排列，这样就能快速找到与当前城市海拔最接近的前驱和后继。

    对于城市 \(i\)，我们关心的是它能够到达的城市（即所有编号大于 \(i\) 的城市）中，距离最近的两个。因为距离是海拔之差的绝对值，所以最近和第二近的城市必然出现在海拔上最靠近 \(h_i\) 的几个城市中。具体而言，只需要考察：

    • 海拔小于 \(h_i\) 的最大城市（前驱）；
    • 海拔小于前驱的最大城市（前驱的前驱）；
    • 海拔大于 \(h_i\) 的最小城市（后继）；
    • 海拔大于后继的最小城市（后继的后继）。

    最多 4 个候选城市，足以覆盖最近和次近的可能性。

    获取候选城市的实现¶

    在 set 中用 lower_bound({h[i], 0}) 找到第一个海拔不小于 \(h_i\) 的元素：

    auto it = st.lower_bound({h[i], 0});

    如果 it 不是 begin()，则 prev(it) 就是前驱；再往前一个就是前驱的前驱。后继则直接从 it 开始取两个（如果存在）。

    将所有这些候选城市放入一个 vector 中，然后按“距离近者优先，距离相同则海拔低者优先”排序。排好序后，第一个候选城市就是小 B 的目的地（最近），第二个就是小 A 的目的地（第二近）。

    排序比较规则：

    bool cmp(const pair<ll,int>& x, const pair<ll,int>& y) {
    ll dx = llabs(x.first - curH);
    ll dy = llabs(y.first - curH);
    if (dx != dy) return dx < dy;
    return x.first < y.first; // 距离相同，海拔低者更近
}

    其中 curH 是当前城市的海拔，用全局变量传递。

    预处理时间复杂度 \(O(n \log n)\)。

    倍增优化¶

    1. 基本单位：一轮¶

    从某个城市 \(i\) 出发：

    • 小 A 先开到第二近城市，记为 \(a = nextA[i]\)，距离 \(distA[i]\)；
    • 然后小 B 从 \(a\) 开到它的最近城市，记为 \(b = nextB[a]\)，距离 \(distB[a]\)。

    这样“A → B”称为一轮。完成一轮后到达城市 \(b\)，且轮到小 A 再次先开车。

    若某一步无法进行（如不存在第二近城市），则这一轮不完整，视为无效。

    2. 倍增状态定义¶

    设 \(j\) 为非负整数，\(i\) 为城市编号。定义：

    • to[j][i]：从城市 \(i\) 出发，走 \(2^j\) 轮 后到达的城市；
    • da[j][i]：走 \(2^j\) 轮过程中，小 A 行驶的总距离；
    • db[j][i]：走 \(2^j\) 轮过程中，小 B 行驶的总距离。

    当 \(2^j\) 轮无法完整完成时，to[j][i] = 0，且距离置为 0。

    3. 初始化（\(j = 0\)）¶

    从城市 \(i\) 出发走 \(2^0 = 1\) 轮，即上述“A一步 + B一步”。

    int a = nextA[i];
if (a && nextB[a]) {
    to[0][i] = nextB[a];
    da[0][i] = distA[i];
    db[0][i] = distB[a];
} else {
    to[0][i] = 0;
    da[0][i] = db[0][i] = 0;
}

    4. 倍增转移（\(j \ge 1\)）¶

    走 \(2^j\) 轮可以拆成两个 \(2^{j-1}\) 轮：先走 \(2^{j-1}\) 轮到某个中间城市，再从这个中间城市走 \(2^{j-1}\) 轮。

    设中间城市为 mid = to[j-1][i]。若 mid 有效（非 0），则：

    \[ \begin{aligned} to[j][i] &= to[j-1][mid] \\ da[j][i] &= da[j-1][i] + da[j-1][mid] \\ db[j][i] &= db[j-1][i] + db[j-1][mid] \end{aligned} \]

    若 mid = 0，表示不能走满 \(2^{j-1}\) 轮，则 \(2^j\) 轮也无效，置 0。

    5. 查询：从起点走不超过 \(x\) 的距离¶

    设当前城市为 cur，剩余可走距离为 rem = x，已累计小 A 路程 sa，小 B 路程 sb。

    先跳整轮：从大到小枚举 \(j\)（例如 \(j=LOG-1\) 到 \(0\)），如果 to[j][cur] != 0 且 da[j][cur] + db[j][cur] <= rem，说明可以完整走 \(2^j\) 轮，则更新：

    sa += da[j][cur];
sb += db[j][cur];
rem -= da[j][cur] + db[j][cur];
cur = to[j][cur];

    这样能在 \(O(\log n)\) 时间内跳过尽可能多的整轮。

    处理剩余的一步：跳完所有整轮后，剩余距离可能不够再走一轮，但可能还够小 A 单独走一步。这是因为一轮包含 A 一步和 B 一步，如果剩余够 A 一步但不够 B 一步，则不能算作整轮被跳过。于是判断：

    if (nextA[cur] && distA[cur] <= rem) {
    sa += distA[cur];
    // 注意：走完这一步后不会再有 B 的步骤，因为如果能走 B 一步，整轮就已经在倍增中跳过了
}

    这样整个查询过程完成。

    复杂度分析¶

    • 预处理最近/次近城市：倒序扫描 + set 查询，\(O(n \log n)\)；
    • 构建倍增表：\(O(n \log n)\)；
    • 回答第一问：枚举所有起点，每个 \(O(\log n)\)，共 \(O(n \log n)\)；
    • 回答 \(m\) 次询问：\(O(m \log n)\)。

    总复杂度 \(O((n+m)\log n)\)，可以通过。

    AC code¶

    #include <bits/stdc++.h>
using namespace std;

using ll = long long;
const int N = 1e5 + 5;
const int LOG = 18;
const ll INF = 1e18;

ll n, m, xstd;
ll h[N];
ll sa, sb;

struct node { ll s, x; } a[N];

int nextA[N], nextB[N];
ll distA[N], distB[N];

int to[LOG][N];
ll da[LOG][N], db[LOG][N];

ll curH; // 辅助比较函数使用

bool cmp(const pair<ll,int>& x, const pair<ll,int>& y) {
    ll dx = llabs(x.first - curH);
    ll dy = llabs(y.first - curH);
    if (dx != dy) return dx < dy;
    return x.first < y.first; // 距离相同，海拔低者更近
}

// 模拟一次行程，累计 sa, sb
void f(ll cur, ll who, ll tot) {
    ll rem = xstd - tot;
    ll cc = cur;

    // 如果轮到 B 先走，先处理 B 的一步
    if (who == 1) {
        if (nextB[cc] && distB[cc] <= rem) {
            sb += distB[cc];
            rem -= distB[cc];
            cc = nextB[cc];
        } else return;
    }

    // 倍增跳整轮
    for (int j = LOG - 1; j >= 0; --j) {
        if (to[j][cc] && da[j][cc] + db[j][cc] <= rem) {
            sa += da[j][cc];
            sb += db[j][cc];
            rem -= da[j][cc] + db[j][cc];
            cc = to[j][cc];
        }
    }

    // 剩余一步给 A
    if (nextA[cc] && distA[cc] <= rem) {
        sa += distA[cc];
    }
}

void init() {
    set<pair<ll,int>> st;
    for (int i = n; i >= 1; --i) {
        vector<pair<ll,int>> cand;
        auto it = st.lower_bound({h[i], 0});
        auto it2 = it;

        if (it != st.begin()) {
            auto itp = prev(it);
            cand.push_back(*itp);
            if (itp != st.begin()) cand.push_back(*prev(itp));
        }
        for (int k = 0; k < 2 && it2 != st.end(); ++k, ++it2)
            cand.push_back(*it2);

        curH = h[i];
        sort(cand.begin(), cand.end(), cmp);

        if (!cand.empty()) {
            nextB[i] = cand[0].second;
            distB[i] = llabs(cand[0].first - h[i]);
        }
        if (cand.size() >= 2) {
            nextA[i] = cand[1].second;
            distA[i] = llabs(cand[1].first - h[i]);
        }
        st.insert({h[i], i});
    }

    // 倍增初始化
    for (int i = 1; i <= n; ++i) {
        int a = nextA[i];
        if (a && nextB[a]) {
            to[0][i] = nextB[a];
            da[0][i] = distA[i];
            db[0][i] = distB[a];
        } else {
            to[0][i] = 0;
            da[0][i] = db[0][i] = 0;
        }
    }

    // 倍增转移
    for (int j = 1; j < LOG; ++j) {
        for (int i = 1; i <= n; ++i) {
            int mid = to[j-1][i];
            if (mid) {
                to[j][i] = to[j-1][mid];
                da[j][i] = da[j-1][i] + da[j-1][mid];
                db[j][i] = db[j-1][i] + db[j-1][mid];
            } else {
                to[j][i] = 0;
                da[j][i] = db[j][i] = 0;
            }
        }
    }
}

void solve1() {
    ll ansA = INF, ansB = 0;
    int id = -1;
    for (int be = 1; be <= n; ++be) {
        sa = sb = 0;
        f(be, 0, 0);
        if (sb == 0) {
            if (ansB == 0 && (id == -1 || h[be] > h[id]))
                id = be;
            continue;
        }
        if (ansB == 0) {
            id = be; ansA = sa; ansB = sb; continue;
        }
        __int128 lhs = (__int128)sa * ansB;
        __int128 rhs = (__int128)ansA * sb;
        if (lhs < rhs || (lhs == rhs && h[be] > h[id])) {
            id = be; ansA = sa; ansB = sb;
        }
    }
    cout << id << '\n';
}

void solve2() {
    for (int i = 1; i <= m; ++i) {
        xstd = a[i].x;
        sa = sb = 0;
        f(a[i].s, 0, 0);
        cout << sa << ' ' << sb << '\n';
    }
}

int main() {
    freopen("drive.in", "r", stdin);
    freopen("drive.out", "w", stdout);
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> n;
    for (int i = 1; i <= n; ++i) cin >> h[i];
    cin >> xstd;
    cin >> m;
    for (int i = 1; i <= m; ++i) cin >> a[i].s >> a[i].x;

    init();
    solve1();
    solve2();
    return 0;
}

    总结¶

    本题的关键是两点：
    1. 利用 set 在倒序扫描时快速找出最近和次近城市；
    2. 将两人各走一步视为一轮，用倍增表加速模拟。

    倍增部分的核心在于状态定义和合并转移，通过一次预处理即可支持多次高效查询。这种“周期动作 + 倍增”的思想在路径规划类题目中非常常见，值得掌握。
