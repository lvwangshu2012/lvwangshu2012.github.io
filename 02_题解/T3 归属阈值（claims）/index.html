    T3 归属阈值（claims）¶

    难度：提高组偏难　|　正解：贪心「能填就填」+ 链表 + 单调栈　|　复杂度 \(O(n)\)

    0. 一句话结论¶

    位置 \(i\) 的归属数就是「以 \(p_i\) 为最大值的区间个数」，它有一个极简公式：

    \(\text{归属数}(i) = (i - L)(R - i)\)

    其中 \(L\) 是 \(i\) 左边最近的比 \(p_i\) 大的位置（没有则 \(0\)），\(R\) 是右边最近的比 \(p_i\) 大的位置（没有则 \(n+1\)）。

    整题就围着这个公式展开：先证明「从小到大填、能填就填」是对的（判可行性），再发现「最小化 \(p_s\)」只取决于 \(s\) 两侧紧贴的连续块长度，用单调栈求出两侧所有可行块长，最后合并。

    1. 核心转化：归属数 = (i−L)(R−i)¶

    以 \(p=(2,1,3)\) 为例：

    位置 \(i\) \(p_i\) \(L\)（左最近更大） \(R\)（右最近更大） 归属数 \((i-L)(R-i)\)
    1 2 0 3 \((1-0)(3-1)=2\)
    2 1 1 3 \((2-1)(3-2)=1\)
    3 3 0 4 \((3-0)(4-3)=3\)

    为什么成立？ 区间 \([l,r]\) 以 \(p_i\) 为最大值，当且仅当区间内没有比 \(p_i\) 大的元素，也就是：

    • 左端点 \(l\) 必须落在 \((L,\ i]\)（不能越过左边第一个更大的 \(L\)）；
    • 右端点 \(r\) 必须落在 \([i,\ R)\)（不能越过右边第一个更大的 \(R\)）。

    左端点有 \(i-L\) 种选法、右端点有 \(R-i\) 种选法，相乘即得。越大的数像「墙」一样把区间挡住，比它小的数随便放都不影响它。

    2. 可行性：「从小到大填」+「能填就填」¶

    2.1 填数视角¶

    按值 \(1,2,\dots,n\) 从小到大填。填到某个值的时候：

    • 已经填的位置：值都比当前小，不挡它；
    • 没填的位置：值将来都比当前大，是墙。

    于是位置 \(i\) 的归属数 = \((i - L)(R - i)\)，其中 \(L,R\) 是 \(i\) 左右最近的未填位置（或边界 \(0/n+1\)）。

    例：\(n=5\)，已填 \(\{1,3\}\)（值更小），现在看位置 \(2\)。它左最近的未填位置是 \(0\)，右是 \(4\)，归属数 \(=(2-0)(4-2)=4\)。位置 \(2\) 能填，当且仅当 \(4 \ge b_2\)。

    2.2 贪心为什么对（交换论证）¶

    关键单调性：填掉一个位置后，其他位置左右未填边界只会变远，归属数只增不减。

    所以「任意一个当前可填的位置，都可以先填」——假设存在某个合法方案，把当前可填的位置 \(x\) 挪到最前面，被它越过的那些位置只是「提前少了一个未填点」（边界更远），条件不会变差。反复这样做，就得到：

    能填就填是既充分又必要的：一直填当前可填的位置；若某刻所有位置都不可填，则无解；能填完 \(n\) 个，则有解。

    2.3 链表 + 队列 \(O(n)\) 实现¶

    • 初始所有位置左右边界就是相邻位置，归属数都是 \(1\)，所以 \(b_i=1\) 的位置先入队。
    • 取出位置 \(i\) 填掉，把它从链表删除；只有它的两个邻居边界变了，重新检查这两个邻居即可。
    • 每个位置入队 \(O(1)\) 次，总 \(O(n)\)。
    // 全数组可行性：能填就填（链表 + 队列）
bool check_all() {
    for (int i = 0; i <= n + 1; i++) { pre[i] = i - 1; nxt[i] = i + 1; done[i] = false; }
    queue<int> q;
    for (int i = 1; i <= n; i++) if (b[i] == 1) q.push(i);
    int filled = 0;
    while (!q.empty()) {
        int i = q.front(); q.pop();
        if (done[i]) continue;
        if (1LL * (i - pre[i]) * (nxt[i] - i) < b[i]) continue; // 还不满足阈值
        done[i] = true;
        filled++;
        int L = pre[i], R = nxt[i];
        nxt[L] = R; pre[R] = L;                                 // 从链表删除 i
        if (L >= 1 && L <= n && !done[L] && 1LL * (L - pre[L]) * (nxt[L] - L) >= b[L]) q.push(L);
        if (R >= 1 && R <= n && !done[R] && 1LL * (R - pre[R]) * (nxt[R] - R) >= b[R]) q.push(R);
    }
    return filled == n;
}

    3. 最小化 \(p_s\)：只看 \(s\) 两侧的连续块¶

    设填 \(s\) 之前，紧贴 \(s\) 左边已经填好的连续块长度为 \(l\)，右边为 \(r\)（这两块里的数都 \(< p_s\)）。

      ...未填...  | 左块 l 个(都<p_s) |  s  | 右块 r 个(都<p_s) |  ...未填...
              ^                                        ^
          位置 s-l-1（墙）                          位置 s+r+1（墙）
    • \(s\) 的归属数 = \((l+1)(r+1)\)，所以必须 \((l+1)(r+1) \ge b_s\)；
    • 两侧共有 \(l+r\) 个数比 \(p_s\) 小，所以 \(p_s \ge l+r+1\)（把 \(1,\dots,l+r\) 填进两侧即可达到下界）。

    于是：

    \(p_s^{\min} = \min\{\ l+r+1 \ \mid\ l \text{ 是左侧可行块长},\ r \text{ 是右侧可行块长},\ (l+1)(r+1)\ge b_s\ \}\)

    为什么不用管两侧之外更远的位置？ 那些位置被「未填的墙」挡住，不影响 \(s\) 的归属数；而它们能否填完，已经由第 2 步的全数组可行性判定保证了。

    4. 单调栈求「一侧可行块长」\(O(n)\)¶

    4.1 重编号 + 栈不变量¶

    把一侧位置按「离 \(s\) 从近到远」重新编号为 \(1,2,\dots,m\)（坐标 \(0\) 是固定不填的 \(s\)，外侧固定边界是 \(m+1\)）：

    左侧： b[s-1], b[s-2], ..., b[1]   →   c[1], c[2], ..., c[s-1]
右侧： b[s+1], b[s+2], ..., b[n]   →   c[1], c[2], ..., c[n-s]

    要回答：对每个 \(r\)，前 \(r\) 个位置能否全部填完？

    用栈维护「还没填、且当前填不掉」的位置（下标递增），栈底永远放固定边界 \(0\)。处理到 \(r\) 时：

    • 先把 \(r\) 压栈；
    • 看栈顶 \(x\)（它下面一个是 \(y\)）：\(x\) 右边没有未填真实位置了，所以左右边界是 \(y\) 和 \(r+1\)，归属数 \(=(x-y)(r+1-x)\)；
    • 若能填（\(\ge c_x\)）就弹出，继续看新栈顶；不能填就停（更左边的位置边界没变，不会突然能填）；
    • 栈里只剩边界 \(0\) ⟺ 前 \(r\) 个全部填完，记 ok[r]=true。
    // c[1..m]：该侧离 s 从近到远的阈值；结果写进 ok[0..m]
void prefixes(int m, bool ok[]) {
    int top = 0;
    st[0] = 0;                 // 栈底固定边界 0（即 s 本身）
    ok[0] = true;              // 空块（长度 0）恒可行
    for (int r = 1; r <= m; r++) {
        st[++top] = r;
        while (top > 0) {
            int x = st[top], y = st[top - 1];
            if (1LL * (x - y) * (r + 1 - x) < c[x]) break; // 填不掉，停
            top--;
        }
        ok[r] = (top == 0);
    }
}

    4.2 一个例子¶

    \(c=(2,1,4,1)\)（栈底边界 \(0\) 省略）：

    \(r\) 压入后的栈 检查与弹出 本轮结束 ok[r]
    1 \([1]\) \(1\times1<2\) 停 \([1]\) 不可行
    2 \([1,2]\) \(2\) 可填；再看 \(1\)，\(1\times2\ge2\) 弹出 \([\ ]\) 可行
    3 \([3]\) \(3\times1<4\) 停 \([3]\) 不可行
    4 \([3,4]\) \(4\) 可填；再看 \(3\)，\(3\times2\ge4\) 弹出 \([\ ]\) 可行

    可行长度为 \(\{0,2,4\}\)。注意可行性不随长度单调（\(1\) 不可行、\(2\) 可行、\(3\) 不可行、\(4\) 可行），所以不能二分，只能逐个求。

    5. 合并左右可行长度¶

    枚举每个可行左长度 \(l\)，需要的右长度 \(r\) 满足 \(r \ge \lceil b_s/(l+1)\rceil - 1 = q\)。

    不能直接取 \(r=q\)（这个长度可能不可行），所以预处理 suf[q] = 不小于 q 的最小可行右长度（从右往左扫一遍即可）。然后：

    suf[mr + 1] = mr + 1;                              // 哨兵：表示不存在
for (int r = mr; r >= 0; r--) suf[r] = right_ok[r] ? r : suf[r + 1];

ll ans = INF;
for (int l = 0; l <= ml; l++) {
    if (!left_ok[l]) continue;
    ll q = (b[s] + l) / (l + 1) - 1;               // ceil(b_s/(l+1)) - 1
    if (q > mr) continue;
    int r = suf[q];
    if (r <= mr) ans = min(ans, (ll)l + r + 1);
}

    样例 1（\(n=5,\ s=2,\ b=(1,4,1,3,1)\)）全程走一遍：

    • 左侧可行长度 \(\{0,1\}\)，右侧可行长度 \(\{0,1,3\}\)；
    • \(l=0\)：需 \(r\ge 3\)，取 \(r=3\)，答案候选 \(0+3+1=4\)；
    • \(l=1\)：需 \(r\ge 1\)，取 \(r=1\)，答案候选 \(1+1+1=3\)；
    • 最终 \(\min=3\)。✓

    6. 完整代码（符合你的编码风格）¶

    #include <bits/stdc++.h>
using namespace std;
using ll = long long;
const int N = 2e5 + 5;
const ll INF = 1e18;

ll n, s;
ll b[N], c[N];                 // b: 各位置阈值; c: 重编号后的阈值
int pre[N], nxt[N];            // 链表（全数组可行性判定用）
bool done[N];
int st[N];                     // 单调栈（求一侧可行长度）
bool left_ok[N], right_ok[N];
int suf[N];                    // suf[q] = 不小于 q 的最小可行右长度

// 全数组可行性：能填就填（链表 + 队列）
bool check_all() {
    for (int i = 0; i <= n + 1; i++) { pre[i] = i - 1; nxt[i] = i + 1; done[i] = false; }
    queue<int> q;
    for (int i = 1; i <= n; i++) if (b[i] == 1) q.push(i);
    int filled = 0;
    while (!q.empty()) {
        int i = q.front(); q.pop();
        if (done[i]) continue;
        if (1LL * (i - pre[i]) * (nxt[i] - i) < b[i]) continue;
        done[i] = true;
        filled++;
        int L = pre[i], R = nxt[i];
        nxt[L] = R; pre[R] = L;
        if (L >= 1 && L <= n && !done[L] && 1LL * (L - pre[L]) * (nxt[L] - L) >= b[L]) q.push(L);
        if (R >= 1 && R <= n && !done[R] && 1LL * (R - pre[R]) * (nxt[R] - R) >= b[R]) q.push(R);
    }
    return filled == n;
}

// 求一侧可行长度：c[1..m] 为该侧离 s 从近到远的阈值
void prefixes(int m, bool ok[]) {
    int top = 0;
    st[0] = 0;
    ok[0] = true;
    for (int r = 1; r <= m; r++) {
        st[++top] = r;
        while (top > 0) {
            int x = st[top], y = st[top - 1];
            if (1LL * (x - y) * (r + 1 - x) < c[x]) break;
            top--;
        }
        ok[r] = (top == 0);
    }
}

void solve() {
    cin >> n >> s;
    for (int i = 1; i <= n; i++) cin >> b[i];

    if (!check_all()) { cout << "-1\n"; return; }   // 1. 全数组可行性

    int ml = s - 1;
    for (int j = 1; j <= ml; j++) c[j] = b[s - j];  // 2. 左侧从近到远
    prefixes(ml, left_ok);

    int mr = n - s;
    for (int j = 1; j <= mr; j++) c[j] = b[s + j];  // 3. 右侧从近到远
    prefixes(mr, right_ok);

    suf[mr + 1] = mr + 1;
    for (int r = mr; r >= 0; r--) suf[r] = right_ok[r] ? r : suf[r + 1];

    ll ans = INF;
    for (int l = 0; l <= ml; l++) {                 // 4. 合并
        if (!left_ok[l]) continue;
        ll q = (b[s] + l) / (l + 1) - 1;
        if (q > mr) continue;
        int r = suf[q];
        if (r <= mr) ans = min(ans, (ll)l + r + 1);
    }
    cout << ans << '\n';
}

int main () {
    freopen("claims.in", "r", stdin);
    freopen("claims.out", "w", stdout);
    ios::sync_with_stdio(false);
    cin.tie(0);
    int T; cin >> T;
    while (T --) solve();
    return 0;
}

    7. 复杂度¶

    • 全数组链表判定：每个位置入队 \(O(1)\) 次，\(O(n)\)；
    • 两次 prefixes：每个位置入栈一次、出栈至多一次，\(O(n)\)；
    • 合并：每个左长度查一次 suf，\(O(n)\)。

    总复杂度 \(O(n)\) 每组，\(O(\sum n)\) 全部，稳稳过 \(2\times10^5\)。 空间 \(O(n)\)。

    8. 你的赛时代码点评（30 分 → 100 分）¶

    你的写法方向是对的：暴力枚举排列 + 特殊性质 A 特判。两个可以改进的点：

    1. 暴力里其实藏着正解的钥匙。你统计归属数用的是「每个区间找最大值位置 +1」，等价于 \((i-L)(R-i)\)。只要换成「从小到大填、用链表维护左右未填边界」，暴力的 \(O(n!\cdot n^2)\) 就变成 \(O(n)\) 的可行性判定。
    2. 特殊性质 A 的特判有两个小 bug： 
      ll x = s - i, y = j - s;              // x=l, y=r
if (x + y + 1 + x * y >= b[i]) {      // bug①：应为 b[s]
    ans = min(ans, ll(j - i + 1 + 1));// bug②：应为 l+r+1 = x+y+1，你算成了 x+y+2
}
      - ① 约束是「\(s\) 的归属数 \((l+1)(r+1)\ge b_s\)」，应比较 b[s]，不是 b[i]（\(i\ne s\) 时 \(b_i=1\)，条件几乎恒真）； - ② 答案是 \(l+r+1\)，你写的 j - i + 2 = x + y + 2 多算了 \(1\)。 修成： 
      if ((x + 1) * (y + 1) >= b[s]) ans = min(ans, x + y + 1);
      这样特殊性质 A 才能稳定拿满 15 分；而正解就是把这个特判推广到「两侧块长要用栈求可行性」的完整版。

    记忆点：遇到「区间最大值 / 贡献个数」类的排列题，先想 (i-L)(R-i)；遇到「从小到大填 + 可填性单调」就上链表/栈；遇到「最小化某个位置的取值」就只看它两侧紧贴的连续块。
