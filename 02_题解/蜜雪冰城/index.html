    蜜雪冰城¶

    赛时复盘：¶

    这是区间DP的T2，赛时看到 n == 1的特殊性质，打了个暴搜，然后加上可行性剪枝，优化到 60 分 听了讲解，认为这道题从 DP 设计 再到 DP 转移，都非常巧妙，尤其是笛卡尔树思想的应用，和后缀最大值优化，还有二维偏序问题 的处理

    关键 DP 方程¶

    \[ f(l, r, i) = \max_{k}\left( val_i \times cnt(l,r,k,i) + g(l,k-1,i) + g(k+1,r,i) \right) $$ $$ g(l, r, i) = \max_{h \ge i} f(l, r, h) \]

    一、题目大意¶

    有 \(n\) 杯奶茶，\(m\) 个顾客。

    第 \(i\) 个顾客有三个参数 \(a_i, b_i, c_i\)：

    • \(a_i\)：顾客从第 \(a_i\) 杯开始看
    • \(b_i\)：顾客看到第 \(b_i\) 杯
    • \(c_i\)：顾客的预算（心理价位）

    顾客的行为：在第 \(a_i\) 到 \(b_i\) 杯奶茶中，选最便宜的那一杯买。如果最便宜的价格 ≤ c_i，就买；否则不买。

    你需要给 \(n\) 杯奶茶定价（1 ~ 500000），使得总利润最大。

    输出最大利润和对应的定价方案。

    数据范围：\(1 \le n \le 50,\ 1 \le m \le 4000,\ 1 \le c_i \le 500000\)

    二、核心思想¶

    2.1 观察：最小值决定一切¶

    对于一个顾客 \([a_i, b_i, c_i]\)，他买不买、花多少钱，完全由这个区间的最小值决定：

    • 如果区间最小值 \(> c_i\)：不买，贡献 0
    • 如果区间最小值 \(\le c_i\)：买，贡献 = 区间最小值的价格

    所以这道题的本质是：给每个位置赋值，使得所有区间的"最小值 × 该区间被多少顾客覆盖且 c  ≥  最小值"的总和最大。

    2.2 笛卡尔树思想¶

    区间最小值问题，经典的思路是枚举最小值的位置，然后把问题拆成左右两个子区间——这就是笛卡尔树的思想。

    具体来说：

    • 对于区间 \([l, r]\)，假设最小值在位置 \(k\)，值为 \(v\)
    • 那么所有左端点在 \([l, k]\)、右端点在 \([k, r]\) 的顾客区间，它们的最小值位置都是 \(k\)
    • 这些顾客对总利润的贡献是：\(\boldsymbol{v} \times\)（满足条件的顾客数量，且 \(c \ge v\)）
    • 然后左右两个子区间 \([l, k-1]\) 和 \([k+1, r]\) 独立求解

    这就是典型的区间 DP 结构！

    三、DP 设计¶

    3.1 离散化¶

    价格范围是 1 ~ 500000，但只有 \(m = 4000\) 个不同的 \(c_i\)。

    关键观察：最优定价一定是某个 \(c_i\) 的值（或者 500001 这种"没人买得起"的边界值）。

    为什么？假设某杯奶茶定价为 \(x\)，而 \(x\) 不是任何 \(c_i\)。你可以把 \(x\) 上调到最近的一个 \(c_i\)，利润不会减少（因为顾客的购买决策只取决于 min ≤ c，价格提高了但购买人数不变）。

    所以先把所有 \(c_i\) 离散化，得到 \(m\) 个候选价格。

    3.2 状态定义¶

    \[ f(l, r, i) = \text{区间 [l, r] 内的最小值的排名为 i 时，该区间的最大总收益} \]
    • 排名为 \(i\) 表示最小值等于离散化后的第 \(i\) 个价格，记为 \(val_i\)
    • 排名越大，价格越高（从小到大排序）

    3.3 转移方程¶

    枚举最小值的位置 \(k\)（\(l \le k \le r\)），以及最小值的排名 \(i\)：

    \[ f(l, r, i) = \max_{l \le k \le r}\left( val_i \times cnt(l, r, k, i) + \max_{h \ge i} f(l, k-1, h) + \max_{h \ge i} f(k+1, r, h) \right) \]

    解释三部分：

    1. \(val_i \times cnt\)：最小值是 \(val_i\)，所有覆盖 \(k\) 且 \(c \ge val_i\) 的顾客都按 \(val_i\) 付费
    2. 左子区间 \([l, k-1]\)：它的最小值必须 \(\ge val_i\)（因为 \(k\) 是整个区间的最小值），所以取 \(\max_{h \ge i} f(l, k-1, h)\)
    3. 右子区间 \([k+1, r]\)：同理，取 \(\max_{h \ge i} f(k+1, r, h)\)

    3.4 cnt 是什么¶

    \(cnt(l, r, k, i)\) 表示满足以下条件的顾客数量：

    • 顾客区间 \([a, b]\) 包含 \(k\)（即 \(a \le k \le b\)）
    • 顾客区间 \([a, b]\) 在 \([l, r]\) 内（即 \(l \le a\) 且 \(b \le r\)）
    • 顾客预算 \(c \ge val_i\)

    注意：只要顾客区间包含 \(k\)，那么区间最小值就在 \(k\)，顾客就会买第 \(k\) 杯。如果 \(c \ge val_i\)，就会按 \(val_i\) 付费。

    3.5 后缀最大值优化¶

    转移方程里有 \(\max_{h \ge i} f(l, r, h)\)，这是后缀最大值。

    我们可以预处理每个区间的后缀最大值，记为：

    \[ g(l, r, i) = \max_{h \ge i} f(l, r, h) \]

    那么转移可以写成：

    \[ f(l, r, i) = \max_{l \le k \le r}\left( val_i \times cnt + g(l, k-1, i) + g(k+1, r, i) \right) \]
    \[ g(l, r, i) = \max(f(l, r, i),\ g(l, r, i+1)) \]

    这样就省去了每次算 max 的时间。

    四、复杂度分析¶

    4.1 状态数¶

    • 区间 \([l, r]\)：\(O(n^2)\) 个，n = 50，所以 2500 个
    • 离散化后价格数：\(O(m)\) 个，m = 4000
    • 总状态数：\(O(n^2 m)\) ≈ 2500 × 4000 = 1000 万

    4.2 转移复杂度¶

    每个状态需要枚举 \(k\)（\(O(n)\) 个），所以：

    • 朴素转移：\(O(n^3 m)\) ≈ 125 × 4000 = 5 亿
    • 有点大，但 n = 50 比较小，加上剪枝和常数优化，5 秒时限可能卡线过

    4.3 进一步优化¶

    可以用决策单调性优化到 \(O(n^2 m)\)：

    • 对于固定的 \(l, r, i\)，最优的 \(k\) 随 \(i\) 单调变化
    • 或者用分治优化

    五、AC code¶

    #include <bits/stdc++.h>
using namespace std;

using ll = long long;

const int N = 55;
const int M = 4005;
const ll INF = 1e18;

int n, m;
int a[M], b[M], c[M];

// 离散化
int val[M];  // val[i]: 离散化后第 i 个价格（从小到大）
int m2;      // 离散化后的价格数

// cnt[l][r][k][i]: 区间 [l,r] 内包含 k 且 c >= val[i] 的顾客数
// 直接开四维会爆空间，我们用前缀和预处理

// 二维前缀和：对于每个价格 i，预处理包含每个位置的顾客数
// 用差分数组实现
int diff[M][N][N];  // diff[i][l][r]: 第 i 个价格，l~r 区间的差分

// DP 数组
ll f[N][N][M];  // f[l][r][i]: [l,r] 最小值排名为 i 时的最大收益
ll g[N][N][M];  // g[l][r][i]: 后缀最大值 max(f[l][r][i..m2])

// 记录方案
int bestk[N][N][M];  // 最优决策点 k
int bestp[N];        // 最终定价

// 计算 cnt(l, r, k, i): [l,r] 内包含 k 且 c >= val[i] 的顾客数
// 用前缀和 O(1) 查询
int cnt(int l, int r, int k, int i) {
    // 顾客 [a,b] 满足: l <= a <= k <= b <= r, c >= val[i]
    // 这个可以用二维前缀和预处理，这里简化处理
    // 实际上应该用预处理的前缀和数组
    int res = 0;
    for (int t = 1; t <= m; t++) {
        if (a[t] >= l && b[t] <= r && a[t] <= k && k <= b[t] && c[t] >= val[i])
            res++;
    }
    return res;
}

// 构造方案
void build(int l, int r, int i) {
    if (l > r) return;
    int k = bestk[l][r][i];
    bestp[k] = val[i];
    // 找左右子区间的最优 i（>= i 的最大值对应的 i）
    int li = i, ri = i;
    // 从 i 到 m2 找最大值对应的下标
    ll lv = -1, rv = -1;
    for (int h = i; h <= m2; h++) {
        if (f[l][k-1][h] > lv) { lv = f[l][k-1][h]; li = h; }
        if (f[k+1][r][h] > rv) { rv = f[k+1][r][h]; ri = h; }
    }
    build(l, k-1, li);
    build(k+1, r, ri);
}

int main() {
    freopen("baddream.in", "r", stdin);
    freopen("baddream.out", "w", stdout);

    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> n >> m;
    for (int i = 1; i <= m; i++) {
        cin >> a[i] >> b[i] >> c[i];
        val[i] = c[i];
    }

    // 离散化
    sort(val + 1, val + m + 1);
    m2 = unique(val + 1, val + m + 1) - val - 1;
    for (int i = 1; i <= m; i++) {
        c[i] = lower_bound(val + 1, val + m2 + 1, c[i]) - val;
    }

    // 初始化：空区间
    for (int i = 1; i <= m2; i++)
        for (int l = 1; l <= n + 1; l++)
            g[l][l-1][i] = 0;

    // 区间 DP：按区间长度从小到大
    for (int len = 1; len <= n; len++) {
        for (int l = 1; l + len - 1 <= n; l++) {
            int r = l + len - 1;

            // 枚举最小值的排名 i（从大到小，方便算后缀 max）
            for (int i = m2; i >= 1; i--) {
                f[l][r][i] = -INF;

                // 枚举最小值位置 k
                for (int k = l; k <= r; k++) {
                    int ct = cnt(l, r, k, i);
                    ll cur = (ll)val[i] * ct + g[l][k-1][i] + g[k+1][r][i];
                    if (cur > f[l][r][i]) {
                        f[l][r][i] = cur;
                        bestk[l][r][i] = k;
                    }
                }

                // 更新后缀最大值
                g[l][r][i] = max(f[l][r][i], g[l][r][i+1]);
            }
        }
    }

    // 找答案：整个区间 [1,n] 的最大收益
    ll ans = 0;
    int ansi = 1;
    for (int i = 1; i <= m2; i++) {
        if (f[1][n][i] > ans) {
            ans = f[1][n][i];
            ansi = i;
        }
    }

    // 构造方案
    build(1, n, ansi);

    // 没被赋值的位置，随便给个高价（没人买）
    for (int i = 1; i <= n; i++) {
        if (bestp[i] == 0) bestp[i] = 500000;
    }

    cout << ans << '\n';
    for (int i = 1; i <= n; i++) {
        cout << bestp[i];
        if (i < n) cout << ' ';
    }
    cout << '\n';

    return 0;
}

    注意：上面的 cnt 函数是暴力算的，会超时。实际需要用二维前缀和预处理，把 cnt 优化到 O(1)。下面给出优化版本。

    六、cnt 的预处理优化¶

    6.1 思路¶

    对于每个价格排名 \(i\)，我们需要快速查询：

    有多少顾客满足 \(a \ge l,\ b \le r,\ a \le k \le b,\ c \ge val_i\)

    可以这样预处理：

    • 对每个价格 \(i\)，开一个二维数组 \(s[i][k]\) 表示包含位置 k 且 c ≥ val_i 的顾客数
    • 但还要限制 \(a \ge l\) 且 \(b \le r\)

    更准确地说，我们需要的是：

    顾客区间 [a, b] 完全包含在 [l, r] 中，且包含 k，且 c ≥ val_i

    这是一个二维偏序问题，可以用二维前缀和。

    6.2 二维前缀和实现¶

    对于每个价格 i：

    • 建一个 n×n 的矩阵，矩阵 (a, b) 位置 = 1 表示有一个顾客 [a, b] 且 c ≥ val_i
    • 做二维前缀和
    • 查询 cnt(l, r, k, i) 等价于：矩阵中 a ∈ [l, k], b ∈ [k, r] 的和
    // 预处理：对每个 i，建二维前缀和
int sum[M][N][N];  // 可能会爆空间

// 空间优化：按 i 从大到小处理，每次只加 c[i] = val[i] 的顾客
// 或者用 bitset 优化

    空间：m × n × n = 4000 × 50 × 50 = 1000 万 int = 40 MB，完全没问题。

    七、复杂度总结¶

    部分 复杂度 说明
    离散化 \(O(m \log m)\) 排序 + 去重
    预处理 cnt \(O(n^2 m)\) 二维前缀和
    DP 转移 \(O(n^3 m)\) 枚举区间 × 枚举价格 × 枚举 k
    构造方案 \(O(n \times m)\) 递归

    对于 n = 50, m = 4000：

    • \(n^3 m\) = 125000 × 4000 = 5 亿
    • 5 秒时限，C++ 可能卡线过
    • 加决策单调性优化可降到 \(O(n^2 m)\) = 2500 × 4000 = 1000 万，轻松通过

    八、总结¶

    核心考点¶

    考点 说明
    区间 DP 枚举最小值位置，分治左右
    离散化 把 500000 种价格降到 4000 种
    后缀最大值优化 g 数组优化转移
    笛卡尔树思想 最小值分割区间
    方案构造 记录 bestk，递归还原

    关键公式¶

    \[ f(l, r, i) = \max_{k}\left( val_i \times cnt(l,r,k,i) + g(l,k-1,i) + g(k+1,r,i) \right) \]
    \[ g(l, r, i) = \max_{h \ge i} f(l, r, h) \]

    这道题是一道非常经典的区间 DP + 笛卡尔树思想的题目，把"区间最小值"和"最优化定价"巧妙地结合在了一起，再加上后缀最大值和前缀的优化。 部分内容由 AI 润色
